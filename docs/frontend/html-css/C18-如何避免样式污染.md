# 如何避免样式污染

> 专题：HTML 与 CSS  
> 编号：C18

### 一句话答案

避免样式污染要控制选择器作用域、命名规范、组件隔离和全局样式边界。

### 常见方案

```text
BEM
CSS Modules
Scoped CSS
CSS-in-JS
命名空间
设计 token
```

### 项目里怎么用

- 组件库样式隔离。
- 业务模块加命名前缀。
- 全局样式只放 reset、变量和基础布局。

### 常见坑

- 全局类名过短。
- 深度选择器滥用。
- 修改组件库内部类名导致升级困难。

### 面试表达

我会把全局样式控制得很少，业务样式尽量模块化。组件库定制优先走变量和 API，不优先用深层选择器强改内部结构。
