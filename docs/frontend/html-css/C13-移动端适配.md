# 移动端适配

> 专题：HTML 与 CSS  
> 编号：C13

### 一句话答案

移动端适配要处理视口、单位、高清屏、点击区域、安全区、键盘和滚动等问题。

### 核心点

```text
viewport meta
rem / vw
devicePixelRatio
安全区 env(safe-area-inset-*)
触摸事件
虚拟键盘
```

### 项目里怎么用

- H5 页面适配不同手机。
- 底部按钮避开安全区。
- 输入框聚焦后处理键盘遮挡。

### 常见坑

- 只在一种手机尺寸测试。
- 固定底部按钮被 iPhone 安全区遮挡。
- 键盘弹起导致布局错位。

### 面试表达

移动端适配不只是 rem，还包括安全区、触摸、键盘和滚动容器。实际项目里我会重点测试 iOS Safari 和 Android WebView。
