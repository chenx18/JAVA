# script defer / async

> 专题：HTML 与 CSS  
> 编号：C05

### 一句话答案

`defer` 和 `async` 都能让脚本下载不阻塞 HTML 解析，但执行时机不同：defer 按顺序等 DOM 解析完执行，async 下载完立即执行且不保证顺序。

### 核心原理

```text
普通 script：下载和执行都会阻塞解析
defer：并行下载，DOM 解析完按顺序执行
async：并行下载，下载完立即执行，不保证顺序
```

### 项目里怎么用

- 有依赖顺序的脚本用 defer。
- 第三方统计脚本可考虑 async。
- 关键脚本避免阻塞首屏。

### 常见坑

- async 脚本依赖 DOM 或其他脚本顺序。
- 第三方脚本阻塞首屏。

### 面试表达

defer 更适合业务脚本，因为顺序稳定且等 DOM 解析后执行；async 更适合独立第三方脚本，比如统计或广告，但要注意它可能提前执行。
