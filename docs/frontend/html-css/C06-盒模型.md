# 盒模型

> 专题：HTML 与 CSS  
> 编号：C06

### 一句话答案

盒模型描述元素由 content、padding、border、margin 组成，`box-sizing` 决定宽高是否包含 padding 和 border。

### 核心原理

```text
content-box：width 只包含内容
border-box：width 包含 content + padding + border
```

### 项目里怎么用

- 全局常设置 `box-sizing: border-box`。
- 表单、卡片、布局计算更稳定。

### 常见坑

- 设计稿宽度和实际元素宽度不一致。
- padding 导致容器撑大。

### 面试表达

我一般会在项目里全局设置 border-box，这样写布局更符合直觉，元素最终宽度更容易控制。
