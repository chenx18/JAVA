# 层叠上下文

> 专题：HTML 与 CSS  
> 编号：C11

### 一句话答案

层叠上下文决定元素在 z 轴上的绘制顺序，z-index 只在同一层叠上下文中比较才有意义。

### 常见触发

```text
position + z-index
opacity < 1
transform
filter
isolation
fixed / sticky
```

### 项目里怎么用

- 处理弹窗、下拉、Tooltip 被遮挡。
- 统一管理 z-index 层级。

### 常见坑

- z-index 设置很大仍然被遮挡。
- 父元素 transform 创建新层叠上下文。
- 多套组件库弹层层级冲突。

### 面试表达

z-index 不生效时，我会先看是否处在不同层叠上下文。弹窗类组件最好统一挂到 body 或根弹层容器，避免被局部层叠上下文限制。
