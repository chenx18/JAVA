# 可访问性

> 专题：HTML 与 CSS  
> 编号：C03

### 一句话答案

可访问性是让不同能力和不同设备的用户都能正常使用页面，包括键盘操作、语义、焦点和读屏支持。

### 核心原理

```text
语义化标签
label
alt
aria
键盘焦点
颜色对比度
```

### 项目里怎么用

- 按钮用 button，不用 div 冒充。
- 图片提供 alt。
- 弹窗打开后管理焦点。
- 表单错误有明确提示。

### 常见坑

- 点击元素没有键盘可达性。
- 只用颜色表达错误状态。
- 弹窗打开后焦点还在背景页面。

### 面试表达

可访问性不是额外装饰，它会影响真实用户体验。即使是后台系统，我也会注意表单 label、按钮语义、键盘操作和错误提示。
