# 定位

> 专题：HTML 与 CSS  
> 编号：C10

### 一句话答案

CSS 定位决定元素在文档流和坐标系统中的位置，常见值有 static、relative、absolute、fixed、sticky。

### 核心原理

```text
relative：相对自身原位置
absolute：相对最近定位祖先
fixed：相对视口
sticky：滚动到阈值后吸附
```

### 项目里怎么用

- 弹层、角标、浮动按钮。
- 固定头部。
- 表格吸顶。

### 常见坑

- absolute 找不到预期定位父级。
- fixed 在移动端和 transform 父级下表现异常。
- z-index 不生效其实是层叠上下文问题。

### 面试表达

定位要先找包含块。absolute 不是永远相对 body，而是相对最近的定位祖先。复杂弹层我一般交给统一 Portal/Teleport 管理，避免层级混乱。
