# 动画

> 专题：HTML 与 CSS  
> 编号：C14

### 一句话答案

前端动画优先使用 CSS transition/animation 或 transform/opacity，避免频繁改变会触发布局的属性。

### 核心原理

更适合动画的属性：

```text
transform
opacity
```

不适合高频动画的属性：

```text
width
height
top
left
margin
```

### 项目里怎么用

- 弹窗出现/消失。
- 抽屉滑动。
- loading。
- 列表过渡。

### 常见坑

- 用 JS 高频改 top/left。
- 动画结束状态和真实 DOM 状态不同步。
- 大量动画同时触发造成卡顿。

### 面试表达

动画优化核心是减少布局和绘制成本。能用 transform 和 opacity 就不要用 top/left/width/height。复杂动画要注意性能和用户可感知体验。
