# 响应式布局

> 专题：HTML 与 CSS  
> 编号：C12

### 一句话答案

响应式布局是让页面在不同屏幕尺寸下保持可用和美观，常结合弹性布局、媒体查询、百分比、断点和容器约束。

### 核心方式

```text
flex / grid
媒体查询
百分比 / vw / rem
max-width / min-width
图片自适应
```

### 项目里怎么用

- 后台系统窄屏适配。
- 移动端页面。
- 仪表盘卡片换行。

### 常见坑

- 只按设计稿固定宽度。
- 文本溢出不处理。
- 表格在移动端完全不可用。

### 面试表达

响应式不是简单等比缩放，而是根据不同宽度调整布局结构。后台系统常见做法是侧边栏收起、表格横向滚动、表单从多列变单列。
