# grid

> 专题：HTML 与 CSS  
> 编号：C09

### 一句话答案

Grid 是二维布局模型，适合同时控制行和列。

### 核心属性

```text
display: grid
grid-template-columns
grid-template-rows
gap
grid-column
grid-row
minmax
repeat
```

### 项目里怎么用

- 仪表盘卡片布局。
- 图片墙。
- 响应式栅格。
- 复杂表单排版。

### 常见坑

- 简单一维布局强行用 grid。
- 不考虑低版本兼容。

### 面试表达

Flex 偏一维，Grid 偏二维。仪表盘和响应式卡片网格我更倾向 grid，工具栏和局部对齐用 flex。
