# 表单

> 专题：HTML 与 CSS  
> 编号：C02

### 一句话答案

表单是用户输入的基础结构，重点是字段语义、校验、可访问性和提交状态管理。

### 核心原理

```text
label 关联 input
name 标识字段
required / type 做基础校验
disabled / readonly 表示不同交互状态
```

### 项目里怎么用

- 后台管理系统表单。
- 登录、注册、搜索筛选。
- 动态表单和复杂校验。

### 常见坑

- label 和 input 未关联。
- disabled 字段不会提交。
- 前端校验和后端校验不一致。
- 表单提交重复点击。

### 面试表达

复杂表单的难点不在输入框本身，而在数据结构、校验规则、联动关系、提交状态和错误回显。前端校验负责体验，后端校验负责最终可信。
