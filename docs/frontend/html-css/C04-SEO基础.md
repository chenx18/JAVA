# SEO 基础

> 专题：HTML 与 CSS  
> 编号：C04

### 一句话答案

SEO 是让搜索引擎更好理解和收录页面，前端关注语义结构、标题描述、可抓取内容、性能和 SSR/预渲染。

### 核心原理

```text
title
meta description
语义化结构
链接可访问
服务端渲染或预渲染
性能指标
结构化数据
```

### 项目里怎么用

- 官网、营销页、文档站重视 SEO。
- 后台管理系统通常 SEO 不重要。
- 单页应用需要考虑 SSR 或预渲染。

### 常见坑

- SPA 首屏只有空 div，爬虫拿不到内容。
- title 和 description 不随路由变化。
- 重要内容由接口异步加载但无 SSR。

### 面试表达

SEO 要看项目类型。后台系统不重，但官网和内容站很重要。SPA 如果需要 SEO，通常要考虑 SSR、SSG 或预渲染。
