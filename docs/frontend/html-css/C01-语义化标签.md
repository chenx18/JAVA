# 语义化标签

> 专题：HTML 与 CSS  
> 编号：C01

### 一句话答案

语义化标签是用符合内容含义的 HTML 标签描述结构，让浏览器、搜索引擎、读屏器和开发者更容易理解页面。

### 核心原理

常见标签：

```text
header
nav
main
section
article
aside
footer
```

### 项目里怎么用

- 内容型页面、官网、文档页面。
- 提升可访问性和 SEO。
- 让页面结构更清晰。

### 常见坑

- 全部用 div。
- 为了语义滥用 section/article。
- 后台系统完全忽略表单 label。

### 面试表达

语义化的价值不只是 SEO，也包括可维护性和可访问性。后台系统虽然 SEO 不重，但表单 label、按钮语义、表格结构仍然重要。
