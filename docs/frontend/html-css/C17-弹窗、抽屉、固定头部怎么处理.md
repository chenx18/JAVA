# 弹窗、抽屉、固定头部怎么处理

> 专题：HTML 与 CSS  
> 编号：C17

### 一句话答案

弹窗和抽屉要统一层级、滚动锁定、焦点管理和关闭逻辑；固定头部要处理遮挡和内容区高度。

### 核心点

```text
Portal / Teleport
z-index 层级规范
body scroll lock
ESC / 遮罩关闭
焦点管理
内容区滚动
```

### 项目里怎么用

- 表单弹窗。
- 详情抽屉。
- 固定筛选栏。

### 常见坑

- 弹窗套弹窗层级混乱。
- 背景页面仍能滚动。
- 固定头部遮挡锚点。

### 面试表达

弹层类组件最好统一挂载和统一层级管理。除了显示隐藏，还要考虑滚动锁定、键盘操作、关闭确认和表单未保存提示。
