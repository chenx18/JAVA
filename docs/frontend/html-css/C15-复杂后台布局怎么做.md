# 复杂后台布局怎么做

> 专题：HTML 与 CSS  
> 编号：C15

### 一句话答案

复杂后台布局通常先拆整体骨架，再处理局部滚动、固定区域、响应式和权限控制。

### 核心结构

```text
AppShell
Header
Sidebar
Tabs / Breadcrumb
Content
Footer / ActionBar
```

### 项目里怎么用

- 侧边栏可收起。
- 顶部固定。
- 内容区独立滚动。
- 表格高度自适应。

### 常见坑

- body 和内容区多重滚动。
- 固定头部遮挡内容。
- 表格高度计算不稳定。

### 面试表达

后台布局重点是稳定和可维护。我会先定义整体布局容器和滚动边界，避免页面出现多个不可控滚动区域，再处理侧边栏、头部、内容区和响应式。
