# 表格和表单页面如何适配

> 专题：HTML 与 CSS  
> 编号：C16

### 一句话答案

表格和表单页面适配要优先保证可读、可操作和不溢出，而不是强行压缩所有内容。

### 核心策略

```text
表单多列变单列
操作按钮折叠
表格横向滚动
固定关键列
字段过长省略和 Tooltip
高级筛选折叠
```

### 项目里怎么用

- B 端后台。
- 移动端审批页。
- 多字段查询页。

### 常见坑

- 表格列太多导致按钮挤压。
- 表单 label 宽度不统一。
- 移动端仍强行展示 PC 表格。

### 面试表达

B 端适配的目标是效率和可用。PC 端可以高信息密度，窄屏则要让筛选项折叠、表格横滚、操作收纳，保证核心操作可完成。
