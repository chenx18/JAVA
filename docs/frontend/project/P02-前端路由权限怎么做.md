# 前端路由权限怎么做

> 专题：项目表达与综合实战  
> 编号：P02

### 一句话答案

前端路由权限一般是在登录后获取权限数据，根据权限动态生成可访问路由，并在路由守卫中校验访问资格。

### 核心原理

```text
登录
获取 token
获取用户信息和权限
生成动态路由
添加到路由表
路由守卫校验
渲染菜单
```

### 项目里怎么用

- Vue Router 用 `beforeEach`。
- React Router 在路由组件外包一层鉴权组件。
- 刷新后根据 token 重新拉用户权限。

### 常见坑

- 动态路由重复添加。
- 刷新页面菜单丢失。
- 只有菜单隐藏，没有直接访问路由拦截。

### 面试表达

我一般会把路由权限分成两个层面：菜单能不能看到，以及 URL 直接访问能不能进。菜单由权限生成，直接访问由路由守卫拦截。刷新时如果有 token，会重新获取用户信息和权限恢复动态路由。
