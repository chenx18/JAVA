# 做过最复杂的前端项目

> 专题：项目表达与综合实战  
> 编号：P04

### 一句话答案

这不是背定义题，而是要准备一个能体现复杂度、职责边界、技术决策、问题排查和结果的数据化项目故事。

### 回答结构

```text
项目背景
业务复杂度
技术架构
你负责什么
遇到什么难点
怎么解决
结果如何
复盘优化
```

### 可讲方向

```text
权限系统
复杂表单
动态配置
多端适配
性能优化
组件库
工程化
线上稳定性
AI 应用交互
```

### 常见坑

- 只说项目很复杂，但没有具体复杂点。
- 只讲用了什么框架，没有讲业务和取舍。
- 没有讲结果和复盘。

### 面试表达

我会选一个最能体现工程经验的项目，而不是功能最多的项目。重点讲我负责的边界、技术难点、怎么定位问题、怎么推动落地，以及最后对业务或团队效率有什么改善。
