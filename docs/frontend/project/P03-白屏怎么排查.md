# 白屏怎么排查

> 专题：项目表达与综合实战  
> 编号：P03

### 一句话答案

白屏排查要先判断是资源加载失败、JS 报错、接口异常、路由配置问题，还是渲染阻塞。

### 核心流程

```text
看控制台错误
看 Network 资源状态
看入口 HTML 是否返回正确
看 JS/CSS 是否 404
看接口是否异常
看路由和权限守卫
看最近发版改动
```

### 项目里怎么用

- 加前端错误监控。
- 捕获资源加载错误和运行时错误。
- 记录版本号、用户环境、路由路径。

### 常见坑

- 线上 publicPath 配错导致静态资源 404。
- 浏览器缓存旧 HTML 引用新旧资源不一致。
- 权限守卫死循环。
- 低版本浏览器不支持新语法。

### 面试表达

我会先看是否有 JS 报错和静态资源 404。如果资源正常，再看接口和路由守卫。线上白屏一定要结合错误监控、版本号和用户环境排查，不能只在本地复现。
