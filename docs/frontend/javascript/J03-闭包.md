# 闭包

> 专题：JavaScript 核心  
> 编号：J03

### 一句话答案

闭包是函数可以访问其创建时的外部作用域，即使外部函数已经执行结束。

### 核心原理

函数创建时会记录词法环境。只要内部函数还被引用，外层作用域里被引用的变量就不会被释放。

### 项目里怎么用

```text
防抖节流
私有变量
函数工厂
缓存中间结果
Hooks 回调
```

### 常见坑

- 旧状态闭包。
- 内存泄漏。
- 循环变量捕获错误。

### 面试表达

闭包的价值是保存上下文。防抖函数需要记住上一次定时器，这就是典型闭包。它也有成本，如果长期引用大对象，就可能造成内存泄漏。
