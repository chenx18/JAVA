# 深拷贝与浅拷贝

> 专题：JavaScript 核心  
> 编号：J07

### 一句话答案

浅拷贝只复制第一层引用，深拷贝会递归复制对象内部结构，避免共享嵌套对象。

### 核心原理

浅拷贝方式：

```text
Object.assign
展开运算符
Array.prototype.slice
```

深拷贝方式：

```text
structuredClone
JSON.parse(JSON.stringify(obj))
递归实现
第三方库 cloneDeep
```

### 项目里怎么用

- 表单编辑时复制原始数据。
- 状态更新避免直接修改原对象。
- 快照、撤销、草稿场景。

### 常见坑

- JSON 深拷贝会丢失函数、undefined、Symbol、Date、Map、Set、循环引用。
- 深拷贝大对象性能差。
- 不必要深拷贝导致性能浪费。

### 面试表达

我会先判断是否真的需要深拷贝。普通一层对象用浅拷贝即可；复杂对象可以用 structuredClone 或工具库。JSON 方案简单但有类型丢失和循环引用问题。
