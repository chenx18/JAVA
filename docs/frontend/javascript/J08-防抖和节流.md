# 防抖和节流

> 专题：JavaScript 核心  
> 编号：J08

### 一句话答案

防抖是停止触发后执行，节流是固定间隔执行。

### 核心原理

防抖用定时器不断推迟执行；节流用时间戳或定时器控制执行频率。

### 项目里怎么用

```text
搜索输入防抖
窗口 resize 防抖
滚动加载节流
拖拽节流
按钮防重复提交
```

### 常见坑

- 不清理定时器。
- 忽略立即执行和尾部执行需求。
- 把防抖用于需要实时反馈的场景。

### 面试表达

我会按场景选择。用户输入搜索一般用防抖，滚动监听一般用节流。实际封装时要考虑立即执行、最后一次执行和组件卸载清理。
