# 原型链

> 专题：JavaScript 核心  
> 编号：J05

### 一句话答案

对象访问属性时，会先找自身，找不到再沿原型链向上查找。

### 核心原理

```text
实例对象
  -> 构造函数.prototype
  -> Object.prototype
  -> null
```

`class` 本质上是原型继承的语法糖。

### 项目里怎么用

- 看懂类和继承。
- 理解实例方法和静态方法。
- 排查属性来自自身还是原型。

### 常见坑

- 混淆 `prototype`、`__proto__`、`constructor`。
- 修改内置原型。
- 原型上放引用类型共享数据。

### 面试表达

原型链解决的是对象属性复用和继承问题。访问属性时如果自身没有，就去原型上找。现代项目里虽然常写 class，但底层仍然是原型机制。
