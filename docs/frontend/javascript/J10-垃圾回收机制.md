# 垃圾回收机制

> 专题：JavaScript 核心  
> 编号：J10

### 一句话答案

垃圾回收负责自动释放不再可达的内存，现代 JS 引擎主要基于可达性分析进行回收。

### 核心原理

从根对象出发，如果一个对象无法被访问到，就可以被回收。

常见根对象：

```text
全局对象
当前调用栈变量
闭包引用
DOM 引用
```

### 项目里怎么用

- 排查内存泄漏。
- 组件卸载时清理定时器、事件监听、订阅、长连接。
- 避免全局缓存无限增长。

### 常见坑

- 定时器未清理。
- 事件监听未解绑。
- 闭包长期引用大对象。
- DOM 被 JS 引用导致无法释放。

### 面试表达

我会从可达性讲垃圾回收。项目里更重要的是内存泄漏排查，比如组件销毁后定时器、监听器、WebSocket、SSE 连接没有释放，都会让对象继续可达。
