# this 指向

> 专题：JavaScript 核心  
> 编号：J04

### 一句话答案

`this` 的值取决于函数调用方式，箭头函数没有自己的 `this`，会捕获定义时外层作用域的 `this`。

### 核心原理

常见规则：

```text
普通函数直接调用：非严格模式指向 window，严格模式为 undefined
对象方法调用：指向调用对象
new 调用：指向新创建的实例
call/apply/bind：显式指定
箭头函数：继承外层 this
```

### 项目里怎么用

- 类组件事件绑定。
- 工具函数避免依赖 this。
- 回调函数里使用箭头函数保持上下文。

### 常见坑

- 把对象方法赋值给变量后再调用，this 丢失。
- 箭头函数不能作为构造函数。
- 在对象字面量里以为箭头函数 this 指向对象。

### 面试表达

我通常不死记 this，而是看调用点。谁调用函数，普通函数里的 this 通常就指向谁；箭头函数没有自己的 this，所以更适合回调，但不适合作为需要动态 this 的方法。
