# 作用域与作用域链

> 专题：JavaScript 核心  
> 编号：J06

### 一句话答案

作用域决定变量在哪里可访问，作用域链决定变量查找顺序。

### 核心原理

JS 采用词法作用域，函数定义在哪里，作用域就基本确定在哪里。查找变量时先查当前作用域，找不到再向外层作用域查找。

### 项目里怎么用

- 解释闭包。
- 避免变量污染。
- 理解模块作用域。
- 排查变量覆盖。

### 常见坑

- `var` 是函数作用域，不是块级作用域。
- 变量提升导致读取到 `undefined`。
- 内外层变量同名造成误读。

### 面试表达

作用域链是变量查找路径。JS 不是看函数在哪里调用，而是看函数在哪里定义。理解这一点后，闭包、变量提升和模块隔离都更好解释。
