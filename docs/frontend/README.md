# 前端复习与 AI 应用索引

这个目录用于恢复前端面试表达，沉淀 8 年前端经验，并逐步补齐 AI 应用前端闭环能力。

当前规则：**进入这个目录的题都按保命题处理**。每一题独立成一个 Markdown 文件，并按专题目录管理。

---

## 推荐复习顺序

当前阶段不要一次啃完整套。建议按优先级推进：

```text
1. javascript/：JavaScript 核心
2. browser/：浏览器、网络、安全
3. engineering/：性能优化与线上排查
4. project/：项目表达与综合实战
5. ai-frontend/：AI 应用前端核心交互
6. vue/ 或 react/：按当前主栈选择深入
7. html-css/：HTML/CSS 基础和布局表达
```

---

## 单题写作结构

每个题目尽量保持这个结构：

```text
1. 一句话答案
2. 核心原理
3. 项目里怎么用
4. 常见坑
5. 面试表达
```

## 新增题目规则

新增题目时继续沿用专题前缀和两位数字：

```text
javascript/J11-xxx.md
browser/B21-xxx.md
engineering/E20-xxx.md
ai-frontend/A27-xxx.md
```

同一专题内保持编号连续，不要把新题放回根目录。
