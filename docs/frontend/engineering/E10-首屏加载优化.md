# 首屏加载优化

> 专题：工程化与性能优化  
> 编号：E10

### 一句话答案

首屏优化是缩短用户看到主要内容的时间，核心是减少阻塞、减小资源、提升缓存和优化接口链路。

### 核心方向

```text
路由懒加载
代码分包
资源压缩
图片优化
CDN
缓存
接口并行
骨架屏
SSR / SSG
```

### 项目里怎么用

- 按路由拆包。
- 图表编辑器延迟加载。
- 图片懒加载。
- 首屏接口并行。

### 常见坑

- 只做 loading，不解决真实瓶颈。
- 第三方脚本阻塞首屏。
- 首页依赖太多非必要接口。

### 面试表达

我会先用 Network 和 Performance 定位瓶颈。如果是 JS 大就拆包，如果是图片大就压缩和懒加载，如果是接口慢就并行、缓存或后端优化。
