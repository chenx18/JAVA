# 图片优化

> 专题：工程化与性能优化  
> 编号：E12

### 一句话答案

图片优化重点是格式、尺寸、压缩、懒加载、响应式和缓存。

### 核心方式

```text
WebP / AVIF
按展示尺寸裁剪
压缩
lazy loading
srcset
CDN
占位尺寸
```

### 项目里怎么用

- 列表缩略图用小图。
- 首屏大图预加载。
- 非首屏图片懒加载。
- 设置 width/height 防 CLS。

### 常见坑

- 原图直接上页面。
- 首屏关键图片也懒加载。
- 图片没有固定尺寸导致布局偏移。

### 面试表达

图片通常是首屏性能大头。我会根据场景选择格式和尺寸，首屏图优先加载，非首屏图懒加载，同时预留尺寸避免 CLS。
