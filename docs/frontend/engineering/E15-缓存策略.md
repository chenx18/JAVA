# 缓存策略

> 专题：工程化与性能优化  
> 编号：E15

### 一句话答案

前端缓存包括 HTTP 缓存、内存缓存、本地存储缓存和业务缓存，要根据数据变化频率和一致性要求选择。

### 核心分类

```text
HTTP 缓存
内存缓存
localStorage / IndexedDB
Service Worker
请求库缓存
字典缓存
```

### 项目里怎么用

- 静态资源长缓存。
- 字典数据缓存。
- 用户信息短期缓存。
- AI 对话历史落库或本地草稿。

### 常见坑

- 缓存过期策略不清。
- 用户切换后还用旧缓存。
- 敏感数据长期存本地。

### 面试表达

缓存要先看一致性要求。静态资源适合强缓存，业务数据要考虑过期、用户隔离和主动刷新。缓存错误比没缓存更难排查。
