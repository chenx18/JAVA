# 运行时卡顿排查

> 专题：工程化与性能优化  
> 编号：E17

### 一句话答案

运行时卡顿通常来自 JS 长任务、频繁重排重绘、大量 DOM、复杂计算或渲染过多。

### 核心工具

```text
Chrome Performance
React/Vue DevTools
Long Task
FPS
Memory
```

### 项目里怎么用

- 录制 Performance 看主线程。
- 找长任务。
- 拆分计算或放 Web Worker。
- 虚拟列表减少 DOM。

### 常见坑

- 只看接口耗时，不看主线程。
- 高频事件未节流。
- 大量 JSON 解析或格式化阻塞 UI。

### 面试表达

卡顿我会先录 Performance，看主线程是不是被长任务占满。如果是计算问题，可以拆分、缓存或放 Worker；如果是渲染问题，就减少 DOM 和不必要更新。
