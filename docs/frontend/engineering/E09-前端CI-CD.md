# 前端 CI/CD

> 专题：工程化与性能优化  
> 编号：E09

### 一句话答案

前端 CI/CD 是把代码检查、测试、构建、产物上传和部署流程自动化，减少人为操作风险。

### 核心流程

```text
代码提交
安装依赖
lint
test
build
产物归档
部署到服务器或对象存储
刷新 CDN
通知结果
```

### 项目里怎么用

- GitLab CI、GitHub Actions、Jenkins。
- 分环境部署。
- 构建版本号注入。

### 常见坑

- CI 环境 Node 版本和本地不一致。
- 没有缓存依赖，构建慢。
- 部署失败没有回滚策略。
- 静态资源和 HTML 发布顺序不当。

### 面试表达

CI/CD 的价值是稳定交付。前端部署要特别注意 HTML 和带 hash 静态资源的发布顺序，避免用户拿到新 HTML 却加载不到对应资源。
