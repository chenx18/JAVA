# 包体积优化

> 专题：工程化与性能优化  
> 编号：E16

### 一句话答案

包体积优化是减少用户需要下载和执行的 JS/CSS，常从依赖、分包、压缩和按需加载入手。

### 核心方式

```text
bundle analyzer
路由懒加载
组件库按需引入
移除重复依赖
替换重库
动态 import
压缩
tree shaking
```

### 项目里怎么用

- 图表库按需加载。
- 富文本编辑器延迟加载。
- 日期库替换或按需引入 locale。

### 常见坑

- 引入整个 lodash。
- moment 全量 locale。
- 多版本依赖重复打包。

### 面试表达

我会先用分析工具看大头在哪里，再决定替换依赖、拆包还是懒加载。体积优化要避免盲改，最后要验证产物变化。
