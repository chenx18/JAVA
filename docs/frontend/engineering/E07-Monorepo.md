# Monorepo

> 专题：工程化与性能优化  
> 编号：E07

### 一句话答案

Monorepo 是把多个相关项目或包放在一个仓库中管理，适合组件库、多应用、多包协作。

### 核心价值

```text
统一依赖
统一规范
跨包改动容易
共享组件和工具
版本联动清晰
```

### 项目里怎么用

- 多个前端应用共享组件库。
- 管理 utils、hooks、UI 包。
- pnpm workspace、Turborepo、Nx 等。

### 常见坑

- 仓库越来越大，构建变慢。
- 包边界不清晰。
- 依赖循环。
- 权限和发布流程复杂。

### 面试表达

Monorepo 适合共享强、协作频繁的项目。它的价值是统一和复用，但需要配合包边界、构建缓存和发布规范，否则会变成大杂烩。
