# Webpack 和 Vite 区别

> 专题：工程化与性能优化  
> 编号：E01

### 一句话答案

Webpack 是基于 bundle 的构建工具，Vite 开发环境利用浏览器原生 ESM 按需加载，启动和热更新通常更快。

### 核心原理

Webpack：

```text
构建依赖图
打包成 bundle
开发环境也围绕打包
生态成熟，定制能力强
```

Vite：

```text
开发环境基于原生 ESM
依赖预构建
源码按需转换
生产环境用 Rollup 打包
启动快，HMR 快
```

### 项目里怎么用

- 老项目和复杂构建链常用 Webpack。
- 新项目、Vue3、React 新应用常用 Vite。
- 迁移时重点看插件、别名、环境变量、代理、静态资源路径。

### 常见坑

- 以为 Vite 生产不打包。
- Webpack 插件不能直接迁移到 Vite。
- CommonJS 依赖在 Vite 下可能需要兼容处理。

### 面试表达

我会从开发环境机制讲差异。Webpack 先打包再服务，Vite 开发环境按需转译和加载，所以启动快。选型不是绝对，老项目稳定性和插件生态也很重要。
