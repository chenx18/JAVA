# 代码分包

> 专题：工程化与性能优化  
> 编号：E03

### 一句话答案

代码分包是把 JS 拆成多个 chunk，按页面或业务场景按需加载，降低首屏包体积。

### 核心方式

```text
路由懒加载
动态 import
第三方库拆包
公共模块拆包
按业务模块拆包
```

### 项目里怎么用

- 后台不同模块路由懒加载。
- 图表、编辑器、富文本等重组件按需加载。
- 管理 vendor chunk。

### 常见坑

- 分包太碎，请求数变多。
- 公共模块重复打包。
- 首屏必要资源被懒加载导致闪烁。

### 面试表达

分包不是越碎越好。我的思路是先控制首屏，重模块延后加载，同时避免公共依赖重复打包。优化后要用构建分析工具看包体积变化。
