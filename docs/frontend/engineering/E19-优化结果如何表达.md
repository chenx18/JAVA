# 优化结果如何表达

> 专题：工程化与性能优化  
> 编号：E19

### 一句话答案

性能优化要用指标和对比表达，不能只说“优化了很多”。

### 表达结构

```text
问题现象
定位工具
瓶颈原因
优化方案
结果数据
风险和取舍
```

### 项目里怎么用

- 首屏从多少秒降到多少秒。
- 包体积减少多少 KB。
- 长列表渲染从多少 DOM 降到多少 DOM。
- 接口请求减少多少次。

### 常见坑

- 没有优化前数据。
- 只讲技术手段，不讲结果。
- 没讲副作用。

### 面试表达

我会尽量用数据讲优化，比如首屏、包体积、接口数量、主线程长任务。没有数据时，也会讲清楚定位过程和为什么选择这个方案。
