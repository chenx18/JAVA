# Source Map

> 专题：工程化与性能优化  
> 编号：E04

### 一句话答案

Source Map 用于把压缩混淆后的线上代码映射回源代码，方便定位错误。

### 核心原理

构建产物记录生成代码与源代码位置的映射关系，错误监控平台可以通过它还原真实源码位置。

### 项目里怎么用

- 线上错误监控还原堆栈。
- 测试环境方便调试。
- 生产环境根据安全要求决定是否公开。

### 常见坑

- 生产 Source Map 直接公开，暴露源码。
- 错误监控没上传对应版本 Source Map。
- 发版版本号和 Source Map 不匹配。

### 面试表达

Source Map 对线上排错很重要，但生产环境要注意安全。我更倾向构建后上传到错误监控平台，而不是直接公开给所有用户访问。
