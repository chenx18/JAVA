# npm / yarn / pnpm

> 专题：工程化与性能优化  
> 编号：E06

### 一句话答案

npm、yarn、pnpm 都是包管理工具，pnpm 通过内容寻址存储和符号链接减少磁盘占用，并且依赖隔离更严格。

### 核心对比

```text
npm：官方默认，生态稳定
yarn：早期提升安装体验
pnpm：安装快、节省空间、依赖结构严格
```

### 项目里怎么用

- 团队统一包管理器。
- 锁定 lockfile。
- CI 使用固定版本。

### 常见坑

- 团队混用包管理器导致 lockfile 混乱。
- 幽灵依赖：代码用了未声明依赖。
- Node 版本不一致导致安装失败。

### 面试表达

我会强调团队一致性。包管理器本身不是重点，重点是 lockfile、Node 版本和 CI 环境一致。pnpm 对幽灵依赖更严格，更适合大型项目和 monorepo。
