# 请求合并

> 专题：工程化与性能优化  
> 编号：E14

### 一句话答案

请求合并是减少无意义的重复请求或多个小请求，降低网络和后端压力。

### 核心方式

```text
接口聚合
并行请求
缓存请求结果
防抖搜索
取消过期请求
批量查询
```

### 项目里怎么用

- 多个字典一次拉取。
- 搜索输入防抖。
- 页面重复进入复用缓存。
- 用户信息全局只请求一次。

### 常见坑

- 盲目聚合导致接口过大。
- 缓存失效策略不清晰。
- 旧请求后返回覆盖新请求结果。

### 面试表达

请求优化不是简单越少越好。高频重复请求要防抖、缓存或取消；强相关的小请求可以后端聚合；无依赖请求可以并行。
