# 组件库

> 专题：工程化与性能优化  
> 编号：E08

### 一句话答案

组件库是把高复用 UI、交互和规范沉淀成可维护资产，提升一致性和开发效率。

### 核心设计

```text
基础组件
业务组件
主题变量
文档示例
类型定义
单元测试
版本发布
设计规范
```

### 项目里怎么用

- 表格、表单、弹窗、上传。
- 权限按钮、字典选择器等业务组件。
- Storybook/VitePress 写文档。

### 常见坑

- 公共组件塞太多业务。
- API 设计不稳定。
- 没有文档，别人不会用。
- 破坏性改动无版本管理。

### 面试表达

组件库不是简单复制组件，而是沉淀稳定能力。公共组件要职责清晰、扩展点明确、文档完整。业务强耦合的东西不一定适合放进通用组件库。
