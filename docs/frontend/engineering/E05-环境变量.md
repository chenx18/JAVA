# 环境变量

> 专题：工程化与性能优化  
> 编号：E05

### 一句话答案

环境变量用于区分 dev/test/staging/prod 等环境配置，比如 API 地址、开关、构建模式等。

### 核心原理

前端环境变量通常在构建时注入，打包后不会动态读取本机环境。

### 项目里怎么用

```text
API baseURL
上传地址
功能开关
错误监控 DSN
构建版本号
```

### 常见坑

- 把密钥放前端环境变量，最终会被打包暴露。
- 以为部署后改 `.env` 不重新构建也能生效。
- dev/test/prod 配置混用。

### 面试表达

前端环境变量不是保密手段，因为最终会进入浏览器。它适合放公开配置，不适合放密钥。部署时要明确哪些是构建期配置，哪些是运行时配置。
