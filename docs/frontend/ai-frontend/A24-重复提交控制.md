# 重复提交控制

> 专题：AI 应用前端专题  
> 编号：A24

### 一句话答案

重复提交控制是避免用户多次点击导致重复请求、重复创建或状态混乱。

### 核心方案

```text
按钮 loading
请求锁
幂等 key
防抖
后端幂等校验
```

### 项目里怎么用

- 登录按钮。
- 文档上传。
- AI 重新生成。
- 表单提交。

### 常见坑

- 只禁用按钮，快捷键或其他入口仍可提交。
- 请求失败后锁未释放。
- 前端防重但后端不幂等。

### 面试表达

重复提交要前后端一起做。前端负责体验层防重，后端最好有幂等机制，特别是创建订单、创建任务、上传文档这类操作。
