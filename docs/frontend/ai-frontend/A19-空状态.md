# 空状态

> 专题：AI 应用前端专题  
> 编号：A19

### 一句话答案

空状态用于引导用户开始操作，AI 应用里常通过示例问题、上传入口和推荐场景降低使用门槛。

### 核心内容

```text
示例问题
上传文档入口
最近知识库
推荐 Prompt
能力边界提示
```

### 项目里怎么用

- 新会话首页。
- 空知识库页面。
- 空搜索结果。
- 文档未上传时的提示。

### 常见坑

- 空白页面没有引导。
- 示例问题和真实能力不匹配。
- 过度营销式文案影响效率。

### 面试表达

AI 产品的空状态很重要，因为用户常不知道该问什么。好的空状态应该给出可点击示例和明确入口，而不是只显示“暂无数据”。
