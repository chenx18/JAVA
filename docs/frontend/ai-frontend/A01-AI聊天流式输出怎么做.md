# AI 聊天流式输出怎么做

> 专题：AI 应用前端专题  
> 编号：A01

### 一句话答案

AI 聊天流式输出是服务端把模型生成的内容分片返回，前端逐步接收、拼接并渲染成消息。

### 核心流程

```text
用户发送问题
前端创建一条 assistant 空消息
发起 SSE 或 fetch stream 请求
持续接收 chunk
增量拼接内容
渲染 Markdown
结束后落库或更新状态
```

### 项目里怎么用

- ChatGPT 类聊天。
- 文档总结实时输出。
- 面试题答案生成。

### 常见坑

- 每个 chunk 都触发复杂 Markdown 渲染导致卡顿。
- 停止生成后请求没取消。
- 错误时消息状态没有恢复。

### 面试表达

我会把流式输出分成请求层、状态层和渲染层。请求层接收增量，状态层维护消息状态，渲染层做节流更新和 Markdown 展示。
