# 停止生成

> 专题：AI 应用前端专题  
> 编号：A14

### 一句话答案

停止生成是用户主动中断当前流式请求，并把当前消息状态标记为已停止。

### 核心流程

```text
用户点击停止
AbortController.abort
关闭 SSE / stream
保留已生成内容
状态改为 stopped
允许继续提问或重新生成
```

### 项目里怎么用

- 长答案生成。
- 模型跑偏时终止。

### 常见坑

- 前端停止了，后端仍继续消耗。
- 已生成内容被清空。
- 停止后按钮状态没恢复。

### 面试表达

停止生成不只是隐藏 loading，而是要真正取消请求。前端要保留已生成内容，状态从 streaming 变成 stopped，必要时通知后端停止任务。
