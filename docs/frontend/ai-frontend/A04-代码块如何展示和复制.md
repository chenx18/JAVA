# 代码块如何展示和复制

> 专题：AI 应用前端专题  
> 编号：A04

### 一句话答案

代码块展示要支持语法高亮、语言识别、复制、横向滚动和移动端适配。

### 核心能力

```text
解析 fenced code block
识别语言
高亮
复制按钮
溢出滚动
复制反馈
```

### 项目里怎么用

- AI 代码回答。
- 面试题代码示例。
- 文档知识库。

### 常见坑

- 代码块太宽撑破布局。
- 复制内容包含额外行号。
- 高亮库体积太大影响首屏。

### 面试表达

代码块是 AI 应用里的关键体验。我会做语言标识、复制按钮和横向滚动，同时高亮库按需加载，避免为了高亮拖慢首屏。
