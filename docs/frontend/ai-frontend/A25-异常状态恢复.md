# 异常状态恢复

> 专题：AI 应用前端专题  
> 编号：A25

### 一句话答案

异常状态恢复是指请求失败、页面离开、网络中断后，页面能回到可继续操作的状态。

### 核心策略

```text
清理 loading
保留用户输入
标记消息失败
提供重试
关闭无效连接
恢复按钮状态
```

### 项目里怎么用

- AI 生成失败后重新生成。
- 文档上传失败后重新上传。
- 网络断开后提示并恢复。

### 常见坑

- loading 卡死。
- 输入内容丢失。
- 请求失败但消息仍显示生成中。

### 面试表达

异常恢复体现产品成熟度。我的原则是失败后不丢用户输入，状态要明确，用户要知道可以重试还是需要修改内容。
