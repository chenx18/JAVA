# 流式消息增量渲染

> 专题：AI 应用前端专题  
> 编号：A12

### 一句话答案

增量渲染是把流式返回的内容追加到当前消息中，并控制状态更新和渲染成本。

### 核心状态

```text
messageId
role
content
status: streaming / done / stopped / error
createdAt
```

### 项目里怎么用

- 先插入 assistant 消息。
- chunk 到来时追加 content。
- 结束时标记 done。

### 常见坑

- 找不到当前流对应哪条消息。
- 多个会话同时生成状态串了。
- 重新生成覆盖旧答案。

### 面试表达

我会给每次生成分配 messageId，把流和消息绑定。这样多会话、多次重新生成、停止生成都能准确更新对应消息。
