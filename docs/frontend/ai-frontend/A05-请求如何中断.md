# 请求如何中断

> 专题：AI 应用前端专题  
> 编号：A05

### 一句话答案

前端可以用 `AbortController` 中断 fetch 或流式请求，用于停止生成、页面离开和防止旧请求覆盖新状态。

### 核心原理

```text
创建 AbortController
请求传入 signal
用户点击停止
调用 abort
捕获 AbortError
更新消息状态
```

### 项目里怎么用

- 停止 AI 生成。
- 搜索条件变化取消旧请求。
- 路由离开时取消请求。

### 常见坑

- 请求取消了，但 UI 仍显示生成中。
- abort 错误被当成普通异常提示。
- 旧请求返回覆盖新请求。

### 面试表达

AI 流式生成必须支持停止。请求层用 AbortController，状态层要把消息从生成中改成已停止，错误处理也要区分主动取消和真实失败。
