# 引用来源展示

> 专题：AI 应用前端专题  
> 编号：A16

### 一句话答案

引用来源展示是 RAG 问答可信度的关键，需要把答案和命中文档片段关联起来。

### 核心内容

```text
文档名
片段标题
页码或位置
相似度
原文片段
跳转链接
```

### 项目里怎么用

- 答案下方引用卡片。
- 文中脚注编号。
- 点击打开原文定位。

### 常见坑

- 引用和答案没有对应关系。
- 来源展示太弱，用户不信任。
- 原文权限未校验。

### 面试表达

RAG 的可信度来自可追溯。前端展示引用来源时，要能让用户看到答案依据，并能点回原文，同时注意文档权限。
