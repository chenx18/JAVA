# 文档解析状态

> 专题：AI 应用前端专题  
> 编号：A17

### 一句话答案

文档解析状态用于告诉用户文件从上传到可问答之间处于哪一步。

### 核心状态

```text
上传中
等待解析
解析中
切片中
向量化中
已完成
失败
```

### 项目里怎么用

- 文档列表状态。
- 进度条。
- 失败原因。
- 重新解析按钮。

### 常见坑

- 状态只有成功/失败，用户不知道卡在哪。
- 后台任务失败前端无感。
- 解析完成前允许问答。

### 面试表达

AI 文档类产品通常是异步流程。前端要把后台任务状态可视化，否则用户只知道上传了文件，不知道什么时候能用。
