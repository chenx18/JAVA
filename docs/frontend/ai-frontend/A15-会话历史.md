# 会话历史

> 专题：AI 应用前端专题  
> 编号：A15

### 一句话答案

会话历史用于保存用户和 AI 的多轮消息，需要考虑本地展示、后端持久化、上下文裁剪和检索。

### 核心字段

```text
conversationId
messageId
role
content
status
model
createdAt
parentId
```

### 项目里怎么用

- 左侧会话列表。
- 消息分页加载。
- 历史搜索。
- 上下文截断提示。

### 常见坑

- 一次加载全部历史导致慢。
- 删除会话后本地状态没同步。
- 多端数据冲突。

### 面试表达

AI 会话历史既是 UI 数据，也是后端业务数据。前端要处理分页、当前会话状态、生成中消息和历史上下文裁剪。
