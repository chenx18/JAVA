# 打字机效果

> 专题：AI 应用前端专题  
> 编号：A11

### 一句话答案

打字机效果是把接收到的文本逐步显示，但要控制渲染频率，避免大量更新造成卡顿。

### 核心方案

```text
接收 chunk
放入缓冲区
requestAnimationFrame 或定时刷新
增量渲染
结束后完整渲染一次
```

### 项目里怎么用

- AI 聊天回答。
- 总结生成过程。

### 常见坑

- 每个 token 都 setState。
- Markdown 每次全量重新解析。
- 光标闪烁和文本换行错乱。

### 面试表达

流式输出不等于每个 chunk 都立刻重渲染。我会做缓冲和节流，保证体验流畅，也避免主线程压力过大。
