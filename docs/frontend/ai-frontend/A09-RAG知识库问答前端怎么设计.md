# RAG 知识库问答前端怎么设计

> 专题：AI 应用前端专题  
> 编号：A09

### 一句话答案

RAG 前端不仅展示答案，还要展示问题、引用来源、命中文档、相似片段和可追溯信息。

### 核心交互

```text
选择知识库
输入问题
流式展示答案
展示引用来源
点击查看原文片段
反馈答案是否有用
支持重新生成
```

### 项目里怎么用

- 企业文档问答。
- 个人学习资料问答。
- 面试题知识库。

### 常见坑

- 只展示答案，没有来源，用户无法信任。
- 引用片段和答案对应不上。
- 知识库未选择就提问。

### 面试表达

RAG 产品的关键是可信。前端要让用户看到答案来自哪些文档、哪些片段，并能回到原文。否则只是一个普通聊天框。
