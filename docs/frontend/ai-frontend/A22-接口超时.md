# 接口超时

> 专题：AI 应用前端专题  
> 编号：A22

### 一句话答案

接口超时要根据接口类型设置不同阈值，AI 流式接口和普通 JSON 接口不能使用同一套超时策略。

### 核心策略

```text
普通接口短超时
上传接口长超时
流式接口看首包和 chunk 间隔
超时后允许重试或取消
```

### 项目里怎么用

- 登录、列表接口快速失败。
- 文档上传和解析提示较长等待。
- 流式生成长时间无输出时提醒。

### 常见坑

- 所有接口统一 10 秒导致 AI 生成被误杀。
- 无超时导致一直 loading。
- 超时后请求实际没取消。

### 面试表达

超时策略要按接口类型区分。AI 流式接口更关注首包时间和长时间无 chunk，而普通接口更适合固定短超时。
