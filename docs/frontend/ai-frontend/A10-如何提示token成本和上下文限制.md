# 如何提示 token 成本和上下文限制

> 专题：AI 应用前端专题  
> 编号：A10

### 一句话答案

前端需要在长文档、长对话和多轮问答中提示上下文限制、截断风险和成本消耗。

### 核心方式

```text
输入长度提示
文档大小限制
超长内容分段
上下文过长提醒
模型选择提示
生成中成本提示
```

### 项目里怎么用

- 上传文档前提示大小限制。
- 长对话提示清理上下文。
- 管理后台显示用量统计。

### 常见坑

- 用户粘贴超长文本后请求直接失败。
- 上下文被截断但用户不知道。
- 成本不可见导致滥用。

### 面试表达

AI 应用要让用户理解限制。前端可以提前提示输入长度、文档大小和上下文状态，避免请求到了后端才失败，也能帮助控制成本。
