# 浏览器缓存

> 专题：浏览器、网络、安全  
> 编号：B09

### 一句话答案

浏览器缓存分为强缓存和协商缓存，前者不请求服务器，后者向服务器确认资源是否变化。

### 核心原理

强缓存：

```text
Cache-Control
Expires
```

协商缓存：

```text
ETag / If-None-Match
Last-Modified / If-Modified-Since
```

### 项目里怎么用

- HTML 入口不做长期强缓存。
- 带 hash 的 JS/CSS 设置长缓存。
- CDN 配合版本化资源。

### 常见坑

- HTML 缓存太久导致资源引用错乱。
- CDN 缓存未刷新。
- 文件不带 hash 导致无法安全长缓存。

### 面试表达

我会把缓存策略分资源类型讲。入口 HTML 要更新及时，静态资源带 hash 后可以长缓存。线上发版异常时，我会看响应头、状态码和 CDN 缓存。
