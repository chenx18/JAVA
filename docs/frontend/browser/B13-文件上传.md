# 文件上传

> 专题：浏览器、网络、安全  
> 编号：B13

### 一句话答案

文件上传通常用 `multipart/form-data`，前端通过 `FormData` 携带文件，后端接收并保存或上传到对象存储。

### 核心原理

```text
input 选择文件
生成 FormData
追加 file 和业务字段
发送 multipart 请求
监听上传进度
服务端保存并返回文件信息
```

### 项目里怎么用

- 头像上传。
- Excel 导入。
- AI 文档解析上传。
- 上传进度条和失败重试。

### 常见坑

- 手动设置 multipart boundary 导致请求错误。
- 文件大小和类型没校验。
- 上传成功但业务处理异步，需要展示处理中状态。

### 面试表达

文件上传不只是调接口，还要处理大小校验、类型校验、进度、失败重试和上传后业务状态。AI 文档场景还要展示解析中、解析失败和重新解析。
