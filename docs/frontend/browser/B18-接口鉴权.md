# 接口鉴权

> 专题：浏览器、网络、安全  
> 编号：B18

### 一句话答案

接口鉴权由后端最终判断用户身份和权限，前端只负责携带凭证、处理状态和控制体验。

### 核心流程

```text
登录获取凭证
请求拦截器携带凭证
后端校验身份
后端校验权限
返回 401 / 403 / 业务错误
前端统一处理
```

### 项目里怎么用

- Axios 拦截器加 Authorization。
- 401 跳登录。
- 403 提示无权限。
- 刷新 token 或重新登录。

### 常见坑

- 只做前端按钮权限。
- token 过期时多个请求同时刷新导致混乱。
- 权限接口和路由生成顺序不稳定。

### 面试表达

前端权限是体验层，接口鉴权是安全层。我的处理一般是请求拦截器带 token，响应拦截器统一处理 401/403，真正的权限判断放后端。
