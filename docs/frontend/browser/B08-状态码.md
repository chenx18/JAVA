# 状态码

> 专题：浏览器、网络、安全  
> 编号：B08

### 一句话答案

HTTP 状态码表示请求处理结果，前端常重点关注 2xx、3xx、4xx、5xx。

### 常见状态码

```text
200 成功
201 创建成功
204 成功但无响应体
301 永久重定向
302 临时重定向
304 缓存未修改
400 参数错误
401 未登录
403 无权限
404 不存在
409 冲突
500 服务端错误
502 网关错误
503 服务不可用
```

### 项目里怎么用

- 请求拦截器统一处理 401、403、500。
- 304 用于缓存判断。
- 业务错误不要全部塞 200，要有清晰约定。

### 常见坑

- HTTP 状态码和业务 code 混乱。
- 401 和 403 不区分。
- 下载接口 204/空响应处理异常。

### 面试表达

我会把状态码和前端处理策略结合讲。401 通常跳登录，403 提示无权限，5xx 走统一异常提示。业务 code 和 HTTP 状态码最好职责清晰。
