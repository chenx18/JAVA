# HTTP / HTTPS

> 专题：浏览器、网络、安全  
> 编号：B06

### 一句话答案

HTTP 是应用层传输协议，HTTPS 是在 HTTP 基础上通过 TLS 提供加密、认证和完整性保护。

### 核心原理

HTTPS 主要解决：

```text
内容被窃听
内容被篡改
服务端身份被伪造
```

### 项目里怎么用

- 生产环境必须 HTTPS。
- Cookie 加 `Secure`。
- 避免混合内容，HTTPS 页面不要加载 HTTP 资源。

### 常见坑

- HTTPS 页面加载 HTTP 图片或脚本被浏览器拦截。
- 证书过期导致接口不可用。
- 本地开发和生产协议不一致导致 Cookie 行为不同。

### 面试表达

HTTPS 不是另一个业务协议，而是 HTTP 加 TLS。它能加密传输、验证服务端身份、防止篡改。线上前端要关注证书、混合内容和安全 Cookie。
