# 大文件分片上传

> 专题：浏览器、网络、安全  
> 编号：B14

### 一句话答案

大文件分片上传是把文件切成多个 chunk 分别上传，服务端接收后合并，常配合断点续传和秒传。

### 核心流程

```text
计算文件 hash
切片
查询已上传分片
并发上传缺失分片
服务端合并
返回文件地址
```

### 项目里怎么用

- 视频上传。
- 大文档上传。
- 模型文件上传。

### 常见坑

- 并发过高压垮网络或服务端。
- hash 计算阻塞主线程。
- 合并失败后缺少恢复机制。

### 面试表达

大文件上传关键是切片、并发控制、断点续传和服务端合并。前端要注意 hash 计算可能耗时，可以放 Web Worker，上传并发也要限制。
