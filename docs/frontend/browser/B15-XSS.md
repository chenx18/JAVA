# XSS

> 专题：浏览器、网络、安全  
> 编号：B15

### 一句话答案

XSS 是攻击者把恶意脚本注入页面执行，从而窃取信息或执行恶意操作。

### 核心类型

```text
存储型
反射型
DOM 型
```

### 项目里怎么用

防护方式：

```text
输入校验
输出转义
富文本白名单
避免直接 innerHTML
CSP
Cookie 设置 HttpOnly
```

### 常见坑

- AI 输出 Markdown 时直接允许 HTML。
- 富文本编辑器内容未过滤。
- 前端拼接 HTML 渲染用户输入。

### 面试表达

XSS 的核心是不可信内容被当成脚本执行。AI 应用里模型输出也不能默认可信，Markdown 和富文本都要做白名单过滤。
