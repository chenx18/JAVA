# 输入 URL 到页面渲染

> 专题：浏览器、网络、安全  
> 编号：B01

### 一句话答案

输入 URL 后，浏览器会完成 URL 解析、DNS、连接、请求响应、HTML 解析、资源加载、DOM/CSSOM 构建、布局、绘制和合成。

### 核心原理

```text
URL 解析
DNS 查询
TCP/TLS 连接
HTTP 请求
服务端响应 HTML
解析 HTML 生成 DOM
解析 CSS 生成 CSSOM
执行 JS
生成渲染树
布局
绘制
合成
```

### 项目里怎么用

- 首屏慢分析。
- 静态资源 404 排查。
- 白屏定位。
- 判断是网络慢、资源大、JS 执行慢还是接口慢。

### 常见坑

- 只讲网络，不讲渲染。
- 忽略 CSS 和同步 JS 对渲染的阻塞。
- 忽略缓存和 CDN。

### 面试表达

我会分两段讲：先是网络请求链路，再是浏览器渲染链路。实际排查首屏问题时，我会用 Network 看资源和接口，用 Performance 看 JS 执行和渲染耗时。
