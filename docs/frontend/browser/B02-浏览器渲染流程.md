# 浏览器渲染流程

> 专题：浏览器、网络、安全  
> 编号：B02

### 一句话答案

浏览器渲染大致是解析 HTML/CSS，生成 DOM/CSSOM，合成渲染树，然后布局、绘制、合成显示。

### 核心原理

```text
HTML -> DOM
CSS -> CSSOM
DOM + CSSOM -> Render Tree
Layout -> Paint -> Composite
```

### 项目里怎么用

- 减少频繁读写布局属性。
- 动画优先使用 transform、opacity。
- 避免大量 DOM 同步更新。

### 常见坑

- 在循环中不断读取 `offsetHeight` 后又修改样式，触发布局抖动。
- 用 top/left 做高频动画。

### 面试表达

我会把渲染流程和性能优化联系起来。布局和绘制成本较高，所以动画尽量使用 transform 和 opacity，让浏览器走合成层，减少重排重绘。
