# 重排和重绘

> 专题：浏览器、网络、安全  
> 编号：B03

### 一句话答案

重排是元素几何信息变化导致重新计算布局，重绘是外观变化但布局不变时重新绘制。

### 核心原理

触发重排：

```text
宽高变化
位置变化
字体变化
DOM 增删
窗口 resize
读取布局属性后修改样式
```

触发重绘：

```text
color
background
box-shadow
visibility
```

### 项目里怎么用

- 批量修改 DOM。
- 使用 class 切换而不是多次直接改 style。
- 动画使用 transform。

### 常见坑

- 高频滚动事件里读写布局。
- 表格大量行更新导致卡顿。

### 面试表达

重排一定会带来重绘，但重绘不一定重排。优化时要减少布局计算次数，尤其是高频事件和动画场景。
