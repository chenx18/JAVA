# GET 和 POST

> 专题：浏览器、网络、安全  
> 编号：B07

### 一句话答案

GET 通常用于获取资源，参数在 URL 中；POST 通常用于提交数据，参数在请求体中。

### 核心区别

```text
语义不同
参数位置不同
缓存行为不同
幂等性预期不同
URL 长度限制不同
```

### 项目里怎么用

- 列表查询用 GET。
- 创建、提交表单用 POST。
- 修改常用 PUT/PATCH。
- 删除常用 DELETE。

### 常见坑

- 用 GET 做有副作用操作。
- 在 URL 里放敏感信息。
- 认为 POST 一定比 GET 安全，实际 HTTPS 才加密传输。

### 面试表达

我会先讲语义。GET 适合查询，POST 适合提交。安全不是由 GET/POST 决定的，而是要看是否使用 HTTPS、鉴权和参数处理。
