# AI 返回内容渲染安全

> 专题：浏览器、网络、安全  
> 编号：B20

### 一句话答案

AI 返回内容不能默认可信，前端渲染 Markdown、HTML、代码块时必须做白名单过滤和危险内容处理。

### 核心风险

```text
模型输出 HTML
用户文档中包含脚本
Markdown 链接伪装
代码块误执行
富文本直接 innerHTML
```

### 项目里怎么用

- Markdown 渲染禁用原始 HTML 或做 sanitize。
- 链接加安全属性。
- 代码块只展示不执行。
- 引用来源和模型输出分层展示。

### 常见坑

- 把模型输出当安全内容。
- 直接 `v-html` / `dangerouslySetInnerHTML`。
- 没有限制链接协议，如 `javascript:`。

### 面试表达

AI 应用前端要把模型输出当用户输入处理，不能因为它是模型生成就直接信任。我的做法是 Markdown 白名单渲染，禁用危险 HTML，链接和代码块都做安全处理。
