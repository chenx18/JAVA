# CSP 内容安全策略

> 专题：浏览器、网络、安全  
> 编号：B19

### 一句话答案

CSP 是通过响应头限制页面可以加载和执行哪些资源，从而降低 XSS 风险。

### 核心原理

常见策略：

```text
default-src
script-src
style-src
img-src
connect-src
frame-src
```

### 项目里怎么用

- 限制脚本来源。
- 禁止内联脚本。
- 限制接口和图片域名。
- AI Markdown 渲染场景降低脚本注入风险。

### 常见坑

- 第三方 SDK 域名没加入白名单。
- 内联脚本被禁止后老代码失效。
- 开发和生产 CSP 不一致。

### 面试表达

CSP 不是替代转义和过滤，而是安全兜底。它能限制脚本来源，即使页面出现注入点，也能降低恶意脚本执行概率。
