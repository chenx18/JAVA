# SSE / WebSocket / 轮询

> 专题：浏览器、网络、安全  
> 编号：B12

### 一句话答案

轮询是客户端反复请求，SSE 是服务端单向推送，WebSocket 是双向长连接。

### 核心对比

```text
轮询：简单但浪费请求
SSE：HTTP 单向推送，适合 AI 文本流
WebSocket：双向通信，适合聊天、协作、游戏
```

### 项目里怎么用

- AI 输出：优先 SSE。
- 在线协作：WebSocket。
- 简单状态刷新：轮询或长轮询。

### 常见坑

- AI 文本流用 WebSocket 过度设计。
- SSE 经过 Nginx 被缓冲。
- 没有处理断线、取消和重试。

### 面试表达

我会按通信方向选型。AI 文本生成是服务端持续给前端推内容，SSE 足够且简单；如果需要双向实时互动，再考虑 WebSocket。
