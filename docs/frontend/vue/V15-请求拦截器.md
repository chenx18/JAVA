# 请求拦截器

> 专题：Vue 专题  
> 编号：V15

### 一句话答案

请求拦截器用于统一处理 token、公共参数、loading、错误、401/403 和响应数据格式。

### 核心流程

```text
请求前加 token
设置 headers
处理 loading
响应后拆业务数据
错误统一提示
401 跳登录
403 提示无权限
```

### 项目里怎么用

- Axios 封装。
- 统一 API 基础路径。
- token 过期处理。

### 常见坑

- 多个请求同时触发 token 刷新。
- 拦截器里做太多业务逻辑。
- 文件下载响应被统一 JSON 处理破坏。

### 面试表达

请求层应该做通用能力，不要塞太多业务。文件下载、流式接口这类特殊响应要单独处理，不能简单套 JSON 拦截。
