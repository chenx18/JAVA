# computed 和 watch 区别

> 专题：Vue 专题  
> 编号：V03

### 一句话答案

`computed` 用于基于响应式数据派生新值，有缓存；`watch` 用于监听变化后执行副作用。

### 核心原理

computed：

```text
依赖不变不重新计算
适合得到一个结果
```

watch：

```text
监听数据变化
适合请求、日志、同步外部状态等副作用
```

### 项目里怎么用

- 总价、过滤结果、展示文案用 computed。
- 搜索条件变化后请求接口用 watch。
- 路由参数变化后刷新详情用 watch。

### 常见坑

- 用 watch 维护一个本可以 computed 得到的值。
- watch 深度监听大对象导致性能问题。
- watch 里修改被监听对象造成循环触发。

### 面试表达

我会把 computed 理解成派生状态，把 watch 理解成副作用监听。如果只是计算展示值，用 computed；如果要发请求、写缓存、调用外部 API，用 watch。
