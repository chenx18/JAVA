# diff 和 key

> 专题：Vue 专题  
> 编号：V09

### 一句话答案

diff 用来比较新旧虚拟 DOM，key 用来标识列表节点身份，帮助 Vue 正确复用和移动节点。

### 核心原理

Vue 会尽量复用节点。稳定 key 可以告诉框架哪个节点对应哪个业务数据。

### 项目里怎么用

- 表格行使用 id。
- 动态表单项使用唯一 id。
- 拖拽排序列表必须使用稳定 key。

### 常见坑

- key 用 index，删除或排序后组件状态错乱。
- key 用随机数，导致每次都重新渲染。

### 面试表达

key 的作用是标识节点身份，不是为了消除 warning。列表有插入、删除、排序时必须使用稳定业务 id。
