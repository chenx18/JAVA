# Vue 项目性能优化

> 专题：Vue 专题  
> 编号：V10

### 一句话答案

Vue 性能优化主要从首屏加载、组件渲染、响应式数据规模、列表渲染和缓存策略入手。

### 核心方向

```text
路由懒加载
组件按需加载
合理使用 computed
避免深度 watch 大对象
长列表虚拟滚动
keep-alive 有边界使用
减少不必要响应式数据
```

### 项目里怎么用

- 大表格使用虚拟列表或分页。
- 大对象不需要响应式时用 markRaw/shallowRef。
- 动态组件按需加载。

### 常见坑

- 所有数据都 reactive。
- 深度监听大对象。
- 大量组件同时挂载。
- keep-alive 无限制缓存。

### 面试表达

我会先定位瓶颈，再做优化。首屏慢看资源和接口，交互卡看组件渲染和响应式数据规模，大列表用分页或虚拟滚动。
