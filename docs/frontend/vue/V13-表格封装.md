# 表格封装

> 专题：Vue 专题  
> 编号：V13

### 一句话答案

表格封装的目标是减少重复代码，同时保留业务扩展能力。

### 核心设计

```text
columns 配置
数据请求
分页
筛选
排序
操作列
插槽扩展
权限控制
```

### 项目里怎么用

- 后台 CRUD 页面。
- 统一分页和 loading。
- 操作按钮按权限展示。

### 常见坑

- 封装过度，业务定制困难。
- 插槽太多导致配置复杂。
- 请求和 UI 强耦合。

### 面试表达

我会把通用能力抽出来，比如分页、loading、列配置和操作列；业务差异通过插槽或 render 函数扩展。封装不能牺牲可读性。
