# 后台管理系统权限

> 专题：Vue 专题  
> 编号：V11

### 一句话答案

Vue 后台权限一般由后端返回菜单和权限码，前端生成动态路由、渲染菜单，并用指令或函数控制按钮展示。

### 核心流程

```text
登录
获取 token
获取用户信息和权限
生成路由
渲染菜单
按钮权限判断
接口 401/403 统一处理
```

### 项目里怎么用

- `router.beforeEach` 判断登录态。
- Pinia 保存权限信息。
- 自定义 `v-permission` 控制按钮。

### 常见坑

- 只做前端按钮隐藏。
- 刷新后动态路由丢失。
- 路由重复添加。

### 面试表达

前端权限只控制体验，后端接口必须鉴权。Vue 中我会用路由守卫和动态路由处理页面权限，用自定义指令处理按钮权限。
