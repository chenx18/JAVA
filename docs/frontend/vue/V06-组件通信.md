# 组件通信

> 专题：Vue 专题  
> 编号：V06

### 一句话答案

Vue 组件通信按关系选择：父子用 props/emits，跨层用 provide/inject，全局共享用 Pinia/Vuex。

### 常见方式

```text
props
emits
v-model
provide / inject
refs
Pinia / Vuex
事件总线，Vue3 中不推荐作为主方案
```

### 项目里怎么用

- 表单组件通过 props 接收配置，emits 输出变更。
- 主题、权限等跨层数据用 provide/inject 或 store。
- 用户信息和菜单权限放 Pinia。

### 常见坑

- 子组件直接修改 props。
- 所有状态都放全局 store。
- 事件总线滥用导致数据流不可追踪。

### 面试表达

我会优先保持单向数据流。父传子用 props，子通知父用 emit；跨很多层再考虑 provide/inject 或 store。全局状态只放真正跨页面共享的内容。
