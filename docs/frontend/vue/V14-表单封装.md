# 表单封装

> 专题：Vue 专题  
> 编号：V14

### 一句话答案

表单封装是通过配置和组件组合统一处理字段渲染、校验、默认值、联动和提交。

### 核心设计

```text
字段配置
组件类型
校验规则
默认值
显隐联动
字典选项
提交转换
```

### 项目里怎么用

- 搜索表单。
- 新增编辑弹窗。
- 动态审批表单。

### 常见坑

- 所有表单都配置化，复杂业务反而难写。
- 字段联动逻辑散落。
- 校验规则和后端不一致。

### 面试表达

我会区分简单表单和复杂表单。通用搜索区可以配置化，复杂业务表单保持组件化，避免配置系统变成另一套难维护语言。
