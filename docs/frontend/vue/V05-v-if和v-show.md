# v-if 和 v-show

> 专题：Vue 专题  
> 编号：V05

### 一句话答案

`v-if` 是条件渲染，会创建和销毁 DOM；`v-show` 是显示隐藏，通过 CSS 控制 display。

### 核心区别

```text
v-if：切换成本高，初始不满足时不渲染
v-show：初始会渲染，切换成本低
```

### 项目里怎么用

- 权限控制、低频弹窗可用 v-if。
- tab 切换、频繁显示隐藏可用 v-show。

### 常见坑

- 用 v-show 控制权限内容，DOM 仍然存在。
- 高频切换用 v-if 导致反复销毁创建。

### 面试表达

如果内容是否存在本身有意义，或者涉及权限，我倾向 v-if；如果只是频繁切换显示状态，v-show 更合适。
