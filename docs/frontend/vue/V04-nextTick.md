# nextTick

> 专题：Vue 专题  
> 编号：V04

### 一句话答案

`nextTick` 用于等待 Vue 完成本轮 DOM 更新后再执行回调。

### 核心原理

Vue 状态变化后不会立刻同步更新 DOM，而是把更新放入队列批量处理。`nextTick` 会在 DOM 更新完成后执行。

### 项目里怎么用

- 数据变化后读取 DOM 高度。
- 弹窗打开后聚焦输入框。
- 列表更新后滚动到底部。

### 常见坑

- 修改数据后马上读 DOM，读到旧值。
- 滥用 nextTick 掩盖组件设计问题。

### 面试表达

Vue 为了性能会批量更新 DOM，所以数据变了不代表 DOM 立刻变了。需要依赖更新后的 DOM 时，我会用 nextTick。
