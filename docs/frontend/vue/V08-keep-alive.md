# keep-alive

> 专题：Vue 专题  
> 编号：V08

### 一句话答案

`keep-alive` 用于缓存组件实例，避免组件切换时被销毁，常用于 tab 页面和列表返回详情后恢复状态。

### 核心原理

被缓存组件不会执行完整销毁和重建，而是触发：

```text
activated
deactivated
```

### 项目里怎么用

- 后台管理系统多标签页。
- 列表页进入详情再返回，保留筛选条件和滚动位置。

### 常见坑

- 缓存后数据不刷新。
- 缓存太多导致内存占用高。
- include/exclude 名称配置错误。

### 面试表达

keep-alive 适合需要保留页面状态的场景，但不能无脑缓存。需要配合 activated 判断是否刷新数据，也要限制缓存范围。
