# 组件复用

> 专题：Vue 专题  
> 编号：V17

### 一句话答案

组件复用不是把所有东西抽成公共组件，而是抽稳定变化少、职责清晰、重复出现的部分。

### 核心原则

```text
职责单一
输入输出清晰
保留插槽扩展
避免强绑定业务
命名和文档清楚
```

### 项目里怎么用

- 搜索表单。
- 表格操作列。
- 上传组件。
- 字典选择器。
- 权限按钮。

### 常见坑

- 过早抽象。
- 组件参数过多。
- 公共组件里写具体业务。

### 面试表达

我会先观察重复是否稳定，再决定抽象。公共组件应该解决一类问题，而不是把某个业务页面硬抽出来给所有人用。
