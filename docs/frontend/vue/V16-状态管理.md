# 状态管理

> 专题：Vue 专题  
> 编号：V16

### 一句话答案

Vue 状态管理要区分局部状态、页面状态和全局状态，不是所有数据都放 Pinia/Vuex。

### 核心分类

```text
组件内部状态
页面查询条件
用户信息
权限菜单
字典缓存
全局配置
```

### 项目里怎么用

- 用户、权限、字典放 store。
- 表格数据放页面内部。
- 搜索条件根据是否需要保留决定是否缓存。

### 常见坑

- store 过大。
- 状态来源重复。
- 页面销毁后状态未清理。

### 面试表达

我会把真正跨页面共享的状态放 store，页面级状态尽量留在页面内。这样数据来源更清晰，也减少全局状态维护成本。
