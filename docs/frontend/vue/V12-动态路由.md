# 动态路由

> 专题：Vue 专题  
> 编号：V12

### 一句话答案

动态路由是根据后端权限或配置，在运行时生成和注册用户可访问的路由。

### 核心原理

```text
后端返回菜单树
前端映射组件
过滤路由
addRoute 注册
生成菜单
```

### 项目里怎么用

- 不同角色看到不同菜单。
- 业务模块按权限开放。

### 常见坑

- 后端返回组件路径无法直接 import。
- 刷新后路由未恢复。
- 404 路由注册顺序错误。

### 面试表达

动态路由的关键是权限数据和前端组件映射。后端通常返回菜单和组件标识，前端用白名单映射到真实组件，不能直接信任任意路径。
