# useEffect

> 专题：React 专题  
> 编号：R02

### 一句话答案

`useEffect` 用于处理渲染后的副作用，比如请求、订阅、定时器、DOM 操作等。

### 核心原理

依赖数组决定执行时机：

```text
不传：每次渲染后执行
[]：首次挂载后执行
[deps]：依赖变化后执行
return：清理副作用
```

### 项目里怎么用

- 首次加载数据。
- 路由参数变化后请求详情。
- 事件监听和定时器清理。

### 常见坑

- 依赖项漏写导致旧值。
- 依赖项多写导致重复请求。
- 没有清理定时器或订阅。

### 面试表达

我会把 useEffect 看成同步组件和外部系统的工具。请求、订阅、定时器都属于副作用。依赖项要按实际使用的外部变量填写，清理函数用于避免内存泄漏。
