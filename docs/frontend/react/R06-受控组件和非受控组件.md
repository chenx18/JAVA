# 受控组件和非受控组件

> 专题：React 专题  
> 编号：R06

### 一句话答案

受控组件的值由 React state 控制，非受控组件的值由 DOM 自己管理，React 通过 ref 获取。

### 核心区别

```text
受控：value + onChange
非受控：defaultValue + ref
```

### 项目里怎么用

- 需要实时校验、联动、提交控制时用受控。
- 简单文件上传或少量 DOM 读取可用非受控。

### 常见坑

- value 从 undefined 变成字符串，引发受控/非受控切换警告。
- 大表单全受控导致频繁渲染。

### 面试表达

受控组件数据流更清晰，适合复杂表单；非受控更轻，适合不需要 React 实时管理的场景。实际项目会结合表单库降低渲染成本。
