# key 的作用

> 专题：React 专题  
> 编号：R09

### 一句话答案

key 用于标识列表元素身份，帮助 React 在 diff 时正确复用、移动或销毁节点。

### 核心原理

React 根据 key 判断新旧列表中哪些元素是同一个。

### 项目里怎么用

- 列表使用业务 id。
- 动态表单项使用唯一 id。
- 拖拽排序不能用 index。

### 常见坑

- 用 index 作为 key，插入删除后状态错乱。
- 用随机数作为 key，每次都重新挂载。

### 面试表达

key 是元素身份，不是序号。只要列表可能插入、删除、排序，就应该使用稳定业务 id。
