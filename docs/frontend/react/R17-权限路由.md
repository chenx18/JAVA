# 权限路由

> 专题：React 专题  
> 编号：R17

### 一句话答案

React 权限路由通常通过路由配置、鉴权组件和用户权限数据共同控制页面访问。

### 核心流程

```text
登录获取 token
获取用户信息和权限
生成可访问路由或过滤菜单
PrivateRoute / AuthGuard 校验
未登录跳登录
无权限跳 403
```

### 项目里怎么用

- React Router 配合 AuthGuard。
- 菜单按权限过滤。
- 按钮按权限码判断。

### 常见坑

- 只过滤菜单，不拦截 URL 直接访问。
- 刷新后权限数据未恢复。
- 异步加载权限时页面闪烁。

### 面试表达

权限路由要同时控制“看不看得到菜单”和“直接访问能不能进”。React 中我一般用鉴权组件包住路由，再配合权限数据过滤菜单。
