# useState

> 专题：React 专题  
> 编号：R01

### 一句话答案

`useState` 用于在函数组件中声明状态，状态变化会触发组件重新渲染。

### 核心原理

```text
声明状态
调用 setState 更新
React 安排重新渲染
组件函数重新执行
返回新的 UI
```

### 项目里怎么用

- 表单输入。
- 弹窗开关。
- 当前选中项。
- 局部 loading。

### 常见坑

- 直接修改对象或数组，不触发预期更新。
- 多次更新依赖旧值时不用函数式更新。
- 认为 setState 后马上能读到新值。

### 面试表达

useState 适合组件内部局部状态。更新对象或数组时要创建新引用，依赖旧值更新时使用函数式写法，避免闭包拿到旧状态。
