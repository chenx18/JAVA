# 表单处理

> 专题：React 专题  
> 编号：R16

### 一句话答案

React 表单处理要平衡受控状态、校验、性能和复杂联动。

### 核心方案

```text
受控组件
非受控组件
表单库
字段级校验
提交态控制
```

### 项目里怎么用

- 简单表单用受控。
- 大型表单用表单库减少重复和渲染。
- 提交时防重复点击。

### 常见坑

- 大表单每个输入都导致整个页面重渲染。
- 校验规则散落。
- 初始值异步加载后表单状态不同步。

### 面试表达

复杂表单我会关注字段结构、校验、联动和性能。大表单不一定全部手写受控状态，可以用表单库做字段级管理。
