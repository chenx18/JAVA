# 组件拆分

> 专题：React 专题  
> 编号：R12

### 一句话答案

组件拆分要按职责、复用性和状态边界拆，而不是单纯按代码行数拆。

### 核心原则

```text
职责单一
数据流清晰
复用稳定
状态就近
避免过度抽象
```

### 项目里怎么用

- 页面容器负责请求和组织。
- 展示组件负责 UI。
- 表单、表格、弹窗拆成可复用组件。

### 常见坑

- 过早抽象。
- 子组件依赖太多父组件细节。
- props 层层透传。

### 面试表达

我会先按职责拆，容器组件处理数据和业务，展示组件关注 UI。重复稳定后再抽公共组件，避免为了复用而复用。
