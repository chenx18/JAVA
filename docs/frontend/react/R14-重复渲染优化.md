# 重复渲染优化

> 专题：React 专题  
> 编号：R14

### 一句话答案

重复渲染优化要先定位渲染来源，再使用 memo、useMemo、useCallback、状态下沉或组件拆分。

### 核心方式

```text
React DevTools Profiler
React.memo
useMemo
useCallback
状态就近
拆分组件
虚拟列表
```

### 项目里怎么用

- 长列表 item memo。
- 复杂计算 useMemo。
- 大页面拆分状态边界。

### 常见坑

- 不分析直接到处 memo。
- props 引用每次变化导致 memo 失效。
- 全局状态变化影响过多组件。

### 面试表达

优化前先用 Profiler 看谁在重复渲染。很多时候问题不是缺 memo，而是状态放得太高，导致父组件更新牵连太多子组件。
