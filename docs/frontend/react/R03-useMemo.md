# useMemo

> 专题：React 专题  
> 编号：R03

### 一句话答案

`useMemo` 用于缓存计算结果，避免每次渲染都重复执行昂贵计算。

### 核心原理

```text
依赖不变，返回上次计算结果
依赖变化，重新计算
```

### 项目里怎么用

- 大列表过滤。
- 复杂统计计算。
- 给 memo 子组件传稳定对象。

### 常见坑

- 滥用 useMemo，计算本身很轻反而增加复杂度。
- 依赖项不完整导致结果错误。

### 面试表达

useMemo 不是默认必用，而是在计算成本高或需要稳定引用时使用。优化前最好先确认真的存在重复计算或渲染问题。
