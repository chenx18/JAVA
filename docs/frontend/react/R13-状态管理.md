# 状态管理

> 专题：React 专题  
> 编号：R13

### 一句话答案

React 状态管理要按状态范围选择：组件内、Context、状态库、服务端缓存分别处理不同问题。

### 核心分类

```text
局部 UI 状态：useState
复杂局部状态：useReducer
跨层上下文：Context
全局业务状态：Redux/Zustand
服务端数据：React Query / SWR
```

### 项目里怎么用

- 表单弹窗状态放组件内。
- 用户信息放全局。
- 接口列表数据可用查询库缓存。

### 常见坑

- 把接口数据全部放 Redux。
- Context 承载频繁变化状态。
- 状态来源重复。

### 面试表达

我会先区分状态类型。不是所有跨组件数据都需要 Redux，服务端数据和客户端 UI 状态也应该分开管理。
