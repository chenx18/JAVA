# 接口请求封装

> 专题：React 专题  
> 编号：R18

### 一句话答案

接口请求封装用于统一 baseURL、headers、token、错误处理、响应格式和特殊请求处理。

### 核心设计

```text
请求实例
请求拦截器
响应拦截器
错误统一处理
业务 code 处理
特殊响应单独处理
```

### 项目里怎么用

- Axios 封装。
- 文件下载。
- 上传进度。
- SSE 流式请求不要套普通 JSON 处理。

### 常见坑

- 所有接口都按 JSON 解析。
- token 过期刷新并发混乱。
- 错误提示重复弹出。

### 面试表达

请求封装要统一但不能僵硬。普通 JSON 接口走统一拦截，下载、上传、SSE 这类特殊接口要单独处理响应类型和错误逻辑。
