# MySQL 专题索引

MySQL 专题用于沉淀 SQL、表设计、约束、索引和数据库兜底能力。

本文档按“可对外发布的教程”组织，不记录个人学习过程、临时排查过程或日期进度。

---

## 专题写作结构

每篇文档尽量采用以下结构：

```text
1. 本节目录 / 学习目标
2. SQL 示例
3. 语法拆解
4. 核心知识沉淀
5. 实际开发注意点
6. 常见误区
7. 面试小题
8. 小结
```

---

## 前置知识与后续路径

MySQL 可以作为独立专题学习，但如果要接入 Spring Boot，建议先理解：

```text
springboot/04-分层架构.md
springboot/11-CRUD模块通用结构.md
```

MySQL 内部依赖关系：

```text
01：知道 SQL 和 MySQL 终端怎么用
  ↓
02：知道如何建库、建表、定义字段
  ↓
03：掌握 insert / select / update / delete
  ↓
04：掌握 where / order by / limit
  ↓
05：理解主键、唯一约束、索引
  ↓
07：理解数据库约束作为最后兜底
  ↓
06：最后整理 SQL 面试表达
```

学完后进入：

```text
mybatis/01-MyBatis是什么.md
mybatis/05-MyBatis XML写法.md
```

## 学习目标

完成基础篇后，应能：

```text
1. 进入 MySQL 终端
2. 查看数据库和表
3. 创建业务表
4. 插入数据
5. 查询数据
6. 修改数据
7. 删除数据
8. 理解 SQL 和 Java CRUD 的对应关系
9. 理解数据库约束如何作为数据兜底
```
