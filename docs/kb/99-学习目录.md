# Java 后端学习路线总览

这份路线用于规划从 Java 基础到后台管理项目开发的学习顺序。

它不是每日学习记录，而是长期可复用的路线图。

---

## 1. 总体目标

学习目标：

```text
能够独立开发一个基础后台管理模块
能够理解 Controller / Service / Mapper / XML 分层
能够使用 MySQL + MyBatis 完成数据库版 CRUD
能够使用 Swagger、Validation、DTO、Lombok 等工程工具
能够向面试官讲清楚模块设计和接口链路
```

---

## 2. 主线学习顺序

```text
Java 基础
  ↓
Spring Boot 接口与分层
  ↓
MySQL 与 SQL
  ↓
MyBatis 持久层
  ↓
参数校验与接口文档
  ↓
事务、日志、批量操作、JOIN
  ↓
项目实战模块
  ↓
面试表达与项目总结
```

---

## 3. 章节依赖关系

每个专题不是孤立的，推荐按依赖关系推进：

```text
看懂 Java 类
  依赖：java/01、java/02、java/03、java/04
  用途：看懂 Entity、DTO、Service、Controller

理解异常
  依赖：java/05
  用途：看懂 NotFoundException、GlobalExceptionHandler

理解状态字段
  依赖：java/06
  用途：看懂 enum、status、字典翻译

写 Spring Boot 接口
  依赖：springboot/01-09
  用途：写 Controller、Service、统一返回、统一异常

写请求和响应对象
  依赖：springboot/10-15
  用途：区分 Entity、DTO、VO、Request、Response

写数据库 CRUD
  依赖：mysql/01-05 + mybatis/01-06
  用途：写 Mapper、XML、SQL、resultMap

写复杂查询
  依赖：mybatis/07-11
  用途：动态 SQL、JOIN、一对多、批量删除

写完整后台模块
  依赖：前面主线 + validation/01-05 + swagger/01-03
  用途：完成可测试、可说明、可面试表达的模块
```

如果只想快速进入项目，最低路线是：

```text
Java 类与异常
  ↓
Spring Boot Controller / Service / Mapper
  ↓
MySQL CRUD
  ↓
MyBatis XML
  ↓
Validation + Swagger
  ↓
后台模块实战
```

## 10. 面试准备方向

重点准备：

```text
Java 基础概念
Spring Boot 分层架构
REST API 设计
MySQL 表设计和约束
MyBatis XML 和动态 SQL
事务使用场景
参数校验和异常处理
Swagger 和接口联调
项目模块表达
```

项目表达模板：

```text
项目采用 Controller、Service、Mapper、XML 分层。
Controller 负责接收请求和返回统一响应。
Service 负责业务校验、事务控制和异常抛出。
Mapper 和 XML 负责数据库操作。
写操作涉及多次数据库变更时使用 @Transactional。
状态字段通过 enum 管理，前端展示通过字典翻译。
```

## 11. 自检清单

每完成一个模块后，可以检查：

```text
是否能独立写出核心代码
是否能解释每一层为什么存在
是否能定位接口异常
是否能读懂 SQL 日志
是否能把当前模块迁移成另一个模块
是否能把知识点沉淀成可发布教程
```
