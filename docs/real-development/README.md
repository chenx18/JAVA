# 真实项目开发流程

这条主线用于学习如何从零完成一个真实的 Java 后台项目。

`docs/kb` 负责解释单个知识点，本文档负责说明这些知识点在项目中什么时候使用、按什么顺序使用，以及每一步需要交付什么结果。

## 学习方式

```text
阅读当前阶段文档
  ↓
手动创建文件和代码
  ↓
启动项目并编译
  ↓
使用 Swagger / Apifox 测试
  ↓
检查代码结构和业务链路
  ↓
整理本阶段知识
  ↓
进入下一阶段
```

学习重点是能够沿着完整链路开发功能：

```text
需求
  ↓
接口设计
  ↓
数据库设计
  ↓
项目结构
  ↓
Entity / Request / Response
  ↓
Mapper / XML
  ↓
Service
  ↓
Controller
  ↓
校验、异常、事务
  ↓
接口测试
  ↓
部署运行
```

## 本阶段项目

使用一个后台管理系统作为训练项目，逐步完成：

```text
用户管理
部门管理
角色管理
菜单管理
数据字典
登录认证
角色权限
Redis 登录态
Docker 部署
```

项目初期只实现必要功能，后续再逐步加入权限、缓存和部署能力。每个模块都按照同一套开发流程完成，形成可以迁移到其他项目的能力。

