# 前端主力、Java 与 AI 应用教材

本教材按专题组织。前端是职业主线，Java与AI用于补齐服务端和应用交付；已有前端经验者可按查漏复习，与Java项目学习并行，不必从第一行顺序重学。

JavaScript 机制篇按口述总览、概念与原因、运行过程、短例和易错点展开；API 篇按用途提供参数、返回值、是否修改原值与就近注意，题目统一放文末。文首 PlantUML 导图附图片预览与可复制源码，字号 14、dpi 100，提醒分支为“注意”。其他系列按各自专题组织，题目用于检验理解，技术检查不代替内容判断。

## 按知识依赖选择路线

- 当前整理顺序：JavaScript 已完成 → TypeScript → Vue 3 → Vue 2 复盘与对比 → HTTP 与浏览器 → 性能与工程化。各专题先覆盖基础用法，再进入原因、边界与高级解释；选读内容按项目补充。
- 前端基础补充：TypeScript、HTML/CSS、浏览器与 HTTP 按岗位和当前模块穿插复习。
- 主力框架：Vue应用 → [Vue原理与源码](04_Vue/02_Vue3原理与源码/00_目录.md) → Vite/Nuxt；有React/RN岗位或项目需求时补对应模型和原生边界。
- 工程能力：测试、性能、安全、CI/CD与项目表达穿插在实际模块开发中。
- Java横向：类型/集合 → 并发与资源 → Spring容器/MVC/事务 → MySQL/Redis → 完整接口交付。
- AI横向：HTTP与异步状态 → 模型API适配 → 流与工具 → 有界Agent/长任务 → RAG → 安全、评估与成本。
- 综合面试：选择真实做过的项目，将机制、取舍、失败路径和验证证据连起来。

## 题目级别与复述方式

P0表示优先掌握，P1表示常见进阶，P2表示按岗位深入；基础、原理、编码、工程取舍标明回答深度。它们不是某家公司或某个年份的必考概率。

先独立回答，再对照正文补缺；记住定义、机制、例子与边界的顺序，改变一个条件检验推导。项目案例是教学材料，不能当作已发生的个人生产经历或虚构规模。

## 示例与版本

普通示例尽量独立，框架、浏览器、Nuxt、Spring或React Native示例会标明上下文。带 `@ts-expect-error` 的行用于类型检查，不应作为业务正常路径执行。

TypeScript静态类型不代替运行时校验；SFC编译不代替浏览器交互；Java片段编译不代替数据库事务集成；模型假适配器不代替供应商接口验证。具体运行和验证说明见[教材说明](README.md)。

API与协议按目标版本查阅官方资料。React19.3、Vue3.5、Nuxt4、当前Vite和MCP2026协议的相关差异在所属章节说明，未来趋势不以未经证实的结论替代基础知识。
