## 二、各知识点详细解释

GC 不是简单“定期清空内存”，而是根据对象可达性判断哪些对象已经没有存活意义，再回收其空间。

现代 GC 经常利用“多数对象生命周期短”的经验，把对象分成不同代，并结合并发和增量工作减少停顿。

G1 把堆划分成 region；ZGC 更强调低停顿目标。具体收集器要结合 JDK 版本和业务延迟目标选择。

## 三、本章面试题与答案

### 题：GC 为什么要分代？

**答案：**

很多对象创建后很快死亡，而长期存活对象比例更低。分代可以让 GC 把更多精力放在新生对象区域，减少扫描整个堆的成本。现代 GC 在此基础上又加入 region、并发标记等机制。
