## 二、知识讲解

<a id="k01"></a>

### 1. JDK、JVM、源码与包

JDK提供javac、java和开发工具，源码编译为字节码，由JVM实现加载执行；运行时可能结合解释和JIT。现代JDK发行形态不必总有单独安装的JRE，部署需匹配项目要求的Java版本。

package声明决定命名空间，目录通常按包结构组织；import导入可使用的类型/静态成员名称，不等于将源文件内容复制进来。同包、java.lang等有默认可见规则，不能单凭资源管理器“在不同文件夹”判断是否需要import。

类名、文件名、可见性和构建源目录必须一致，Maven/Gradle管理依赖和编译流程；IDE红线与真实编译失败要分别验证。

<a id="k02"></a>

### 2. 对象、构造器与参数传递

```java
public class Example {
    static class User {
        private final String name;
        User(String name) { this.name = name; }
        String name() { return name; }
    }
    static void replace(User user) { user = new User("B"); }
    public static void main(String[] args) {
        User user = new User("A");
        replace(user);
        System.out.println(user.name()); // A
    }
}
```

构造器初始化对象，无返回类型，可按参数列表重载；this区分当前对象成员与局部变量。Java参数始终按值传递，对象参数复制引用值；重新给形参赋值不会替换调用方变量。

封装使对象维护自身合法状态，不只是把字段设private再无条件开放所有setter。final引用不能重新赋值，不代表被引用对象全部不可变。

<a id="k03"></a>

### 3. 继承、接口与多态

接口描述能力/契约，抽象类可承载共有状态与部分实现；现代接口还可有default/static/private方法，不能说接口永远只有抽象方法。类单继承，可实现多个接口。

父类型引用指向子对象时，可重写实例方法按实际对象分派；字段、static方法和构造器不按同一方式参与动态多态。组合常适合灵活业务行为，不必为复用建立深层继承。

访问修饰符public/protected/包可见/private控制暴露范围，模块和包边界也影响可见性。服务接口应稳定而小，不把全部实现细节当公共API。

<a id="k04"></a>

### 4. 重载、重写与静态成员

重载是同名不同参数列表，调用选择主要发生在编译期，不能只靠返回类型区别；构造器也能重载。重写是子类对可重写实例方法提供实现，应使用@Override让编译器检查签名。

static属于类相关结构，不依赖某个实例；final方法不可重写，final类不可继承，final变量限制重新赋值。接口默认方法冲突需要按语言规则明确解决。

面试说明多态时要给“声明类型影响可见方法，实际对象影响重写实现”的例子，不把所有同名方法都称为多态。

<a id="summary"></a>

## 三、知识小结

Java先编译再运行，包与类型建立边界；对象维护状态，接口表达契约，动态分派作用于可重写实例方法。参数按值传递，重载与重写发生在不同选择层次。

## 四、面试题与答案

<a id="java01-01"></a>

### JAVA01-01 [P0·基础] JDK和JVM分别是什么？

**回答：** JDK包含开发和运行工具，JVM是执行字节码的虚拟机规范及其实现体系。项目编译目标和部署运行时需兼容，安装一个IDE不代表所有命令与依赖配置完成。

对应讲解：[JDK、JVM、源码与包](#k01)。

<a id="java01-02"></a>

### JAVA01-02 [P0·原理] Java对象参数是引用传递吗？

**回答：** 参数按值传递，对象场景复制的是引用值，所以可修改同一对象，但形参重新赋值不会替换调用方变量。与“传引用”模型要通过重绑例子区分。

对应讲解：[对象、构造器与参数传递](#k02)。

<a id="java01-03"></a>

### JAVA01-03 [P0·基础] 重载和重写怎么区分？

**回答：** 重载依靠参数列表区别同名方法并在编译期选择，返回类型单独不同不构成重载；重写在继承契约下替换实例方法实现，运行时按实际对象分派。

对应讲解：[重载、重写与静态成员](#k04)。

<a id="java01-04"></a>

### JAVA01-04 [P1·工程取舍] 接口和抽象类如何选择？

**回答：** 接口适合能力和可替换契约，抽象类适合确有共享状态与部分实现的继承结构。现代接口不只有抽象方法，业务复用也可用组合，不能仅按代码复用量决定继承。

对应讲解：[继承、接口与多态](#k03)。
