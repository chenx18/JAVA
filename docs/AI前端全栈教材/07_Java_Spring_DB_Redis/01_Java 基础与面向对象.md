## 二、各知识点详细解释

Java 是静态类型语言，源码经过编译生成字节码，再运行在 JVM。面向对象的核心不是背“封装继承多态”三个词，而是理解对象责任、抽象边界和运行时多态。

### 重载与重写

Overload：同一类中方法名相同、参数列表不同，编译期决定调用。

Override：子类重新实现父类/接口允许重写的方法，运行期根据实际对象决定具体实现，构成多态。

### interface 与 abstract class

Interface 更适合表达能力/契约；abstract class 可以共享状态和部分实现。现代 Java 中 interface 已经可以包含 default/static/private 方法，因此二者不是简单的“接口只能写抽象方法”。

## 三、本章面试题与答案

### 题：Java 多态怎么实现？

**答案：**

通常通过父类引用指向子类对象，调用可重写方法时在运行期根据对象实际类型选择实现。它依赖继承/接口和方法重写，体现的是同一调用接口对应不同实现。

### 题：重载和重写区别？

**答案：**

重载主要发生在同一作用域/类中的方法签名不同，属于编译期选择；重写要求子类对父类或接口的可重写方法提供新的实现，调用时体现运行期多态。
