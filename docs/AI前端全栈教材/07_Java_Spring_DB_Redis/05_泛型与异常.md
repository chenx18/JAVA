# 第五章 泛型与异常

## 一、本章具体知识点

- Generic
- bounded type
- wildcard
- extends / super
- type erasure
- Exception
- RuntimeException
- checked exception
- try/catch/finally
- try-with-resources

## 二、各知识点详细解释

泛型让集合、方法和类保留更强类型关系。Java 泛型主要通过类型擦除实现，因此运行时通常无法直接知道普通泛型参数的具体类型。

异常分为 Error 和 Exception；Exception 中又有 checked 与 unchecked。业务代码常通过明确异常类型、统一异常处理和日志来管理错误。

try-with-resources 可以自动关闭 AutoCloseable 资源。

## 三、本章面试题与答案

### 题：Java 泛型为什么叫类型擦除？

**答案：**

很多泛型信息主要在编译期参与类型检查和生成必要的强制转换，运行时普通泛型参数信息通常被擦除为原始类型/上界，因此不能像某些具体运行时泛型系统那样随意查询 T 的真实类型。这个设计保持了与旧版 Java 字节码的兼容性。

### 题：checked 和 unchecked exception 区别？

**答案：**

checked exception 要求编译器保证被捕获或声明抛出，通常表示调用方有机会恢复的外部条件；unchecked exception 主要继承 RuntimeException，不强制调用方声明。实际项目不应该机械地把所有异常都变成 checked exception。
