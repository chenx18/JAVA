# 第十五章 综合面试：从需求到全栈闭环

## 一、本章具体知识点

- requirement decomposition
- domain model
- frontend architecture
- backend architecture
- database
- auth
- AI
- observability
- deployment

## 二、各知识点详细解释

一个完整需求不能直接进入“写页面”。

```text
需求
→ User Story
→ Domain Model
→ API Contract
→ DB Schema
→ Frontend State
→ Backend Service
→ AI Workflow
→ Security
→ Test
→ Deploy
```

例如“企业 AI 知识库”：

```text
User
→ Workspace
→ Knowledge Base
→ Document
→ Chunk
→ Embedding
→ Retrieval
→ Chat
→ Citation
```

## 三、本章面试题与答案

### 题：如果让你一个人从 0 做一个 AI SaaS，你怎么开始？

**答案：**

先定义最小业务闭环和用户角色，再设计核心数据模型与 API 契约；前端用 Vue/Nuxt 实现页面和交互，后端用 Spring Boot 管业务和权限，数据库保存用户、工作区、文档、消息等，Redis 做缓存/限流，AI Gateway 接模型，RAG/Agent 做 AI 能力。第一版本优先完成登录、核心业务、AI 主流程和审计，之后再增加异步任务、水平扩展和多模型路由。
