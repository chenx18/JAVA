## 二、各知识点详细解释

最终复习不要按“题号”复习，要按知识链复习。

例如 Vue：

```text
Proxy
→ reactive
→ track
→ trigger
→ effect
→ scheduler
→ component render
→ patch
```

AI：

```text
HTTP
→ Streaming
→ SSE
→ Parser
→ State Machine
→ Vue Reactive State
→ UI
```

Java：

```text
Thread
→ Memory Model
→ volatile/CAS/lock
→ ThreadPool
→ Spring Transaction
→ DB
```

## 三、本章面试题与答案

### 题：你最大的技术优势是什么？

**答案模板：**

以技术事实回答，而不是泛泛说“学习能力强”。可以表达为：自己的主力前端是 Vue 3/Nuxt，有 React/RN 跨框架和跨端经验，同时在补 Java/Spring Boot 后端，并把 AI Streaming、Tool Calling、Agent、MCP 等能力接到完整业务系统中，因此能够从前端界面一直走到 API、数据层和 AI 工作流。

### 题：为什么最近开始学 Java？

**答案模板：**

不是为了从前端转成纯 Java，而是希望补齐服务端能力。过去主要从 API 消费方理解系统，现在希望能够自己设计数据模型、事务、权限和服务端接口，再把 Vue/Nuxt 与 AI 能力接起来，形成完整产品闭环。
