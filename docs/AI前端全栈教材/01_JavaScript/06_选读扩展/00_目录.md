# 选读扩展

按项目需要学习逐项消费、后台计算、流式响应和音频采集。它们不作为进入 Vue 的前置门槛；每篇都要区分语言规则、浏览器能力和真实环境验证。

## 本组掌握标准

本组按项目选择主题，不要求四篇全部完成。下面的层次用于检查已选择的主题。

- **基础：** 说明该能力解决什么问题，以及普通函数、Promise 或页面线程为什么不足；分清生成器推进、Worker 通信、流式消息和录音资源各自的规则。
- **中级：** 跑通所选主题的最小示例，按明确协议处理结果、失败、结束与取消，不把收到一段字节等同于收到一条完整消息。
- **高级：** 在真实运行环境验证边界和成本，例如 Worker 通信开销、流式分帧与消费积压、录音权限及设备差异；能解释为何采用或放弃方案。
- **自查练习：** 四选一：验证生成器提前结束时的清理；比较同一计算在页面与 Worker 中的表现；分段输入 SSE 并取消消费；完成录音、停止和预览释放。保留运行结果及尚未验证的范围。

整体层次和进入 Vue 的条件见[复习达标标准](../00_学习导航.md#learning-standard)。

本组 4 篇正文、18 道分级题。“知识点归纳与自查”和“试题与答案”分别成节，自查不计入分级题数。文件在本组内从 01 起排序；D/C为固定检索编号，与分类内文件顺序独立。

机制篇先给口述总览，再解释概念、原因和运行过程，用短例与条件变化检验理解。API 篇按用途说明功能、调用形式、参数、返回值、是否修改原值和就近注意；两种风格按主题选择，不要求每篇写成同一种结构。
