# 03 函数

函数是可以被调用的对象，也是组织输入、输出和副作用的单位。本章先明确函数的分类，再比较各类行为，最后讲参数、返回值和常见函数抽象。this、闭包和异步机制各有专篇深入。

## 二、知识讲解

<a id="k01"></a>

### 1. 函数是什么：可调用对象与一等值

函数可以赋给变量、放进对象或数组、传给另一个函数、再作为结果返回。这种与其他值一样参与程序组织的能力，称为一等值。

```js
function applyTwice(fn, value) {
  return fn(fn(value));
}
const addOne = n => n + 1;
console.log(applyTwice(addOne, 3)); // 5
console.log(typeof addOne); // function
```

回调只是函数的一种使用角色：把函数交给别人，在某个时机调用。回调不必匿名、不必异步；Array.map中的回调通常同步执行。函数还能拥有属性，但函数对象属性与每次调用的局部变量不是同一份存储。

“能被typeof识别为function”和“能任意方式调用”也不同，class不能直接当普通函数调用，某些宿主函数也有接收者约束。

<a id="k02"></a>

### 2. 定义形式：声明、表达式、方法、箭头

| 定义形式 | 示例 | 初始化与主要特点 |
| --- | --- | --- |
| 函数声明 | function add(a,b){} | 普通声明通常在所属作用域执行前初始化 |
| 函数表达式 | const add=function(a,b){} | 函数值在表达式求值时产生，绑定受const等声明规则影响 |
| 方法简写 | const obj={add(a,b){}} | 普通方法按调用接收者绑定this，不可new |
| 箭头函数 | const add=(a,b)=>a+b | 词法this，无自身arguments，不可new |
| Function构造器 | new Function('a','return a+1') | 动态编译文本，通常在全局环境解析外部名字 |

匿名与命名是另一个维度。表达式可以命名：const f=function inner(){}；inner主要在函数自身内部可见，适合递归和调试，不会自动给外层创建同名变量。匿名表达式的name也可能由赋值上下文推断，不能把name当稳定业务身份。

IIFE表示立即调用函数表达式，如(function(){...})()或(()=>{...})()；它是调用形态，不是第六种互斥函数类型。现代模块已经提供作用域隔离，IIFE仍可用于局部初始化，但不是所有代码都需要包一层。

new Function/eval不是正常复用代码的优先方案，它们有作用域差异、CSP限制和执行不可信文本的风险。

<a id="k03"></a>

### 3. 执行形态：普通、async、Generator

| 形态 | 调用后的主要结果 | 函数体何时推进 |
| --- | --- | --- |
| 普通函数 | return值，未返回为undefined | 当前调用中执行 |
| async函数 | Promise | 先同步到第一个实际await，之后恢复调度 |
| function*生成器 | 生成器对象 | next等操作才推进，到yield暂停 |
| async function* | 异步生成器对象 | next结果为Promise，支持await/yield |

```js
function normal() { return 1; }
async function asynchronous() { return 1; }
function* generator() { yield 1; }
console.log(normal()); // 1
console.log(asynchronous() instanceof Promise); // true
console.log(generator().next()); // {value:1,done:false}
```

普通函数声明/表达式一般可构造，但async、生成器、箭头和方法简写不能据此统称可构造。“回调、高阶、递归、构造函数”描述用途；一个async箭头可以同时是回调，所以分类应按维度解释。

<a id="k04"></a>

### 4. 普通函数与箭头函数的区别

| 维度 | 一般function函数 | 箭头函数 |
| --- | --- | --- |
| this | 普通调用按本次调用方式决定 | 不建立自己的this，沿外层环境读取 |
| arguments | 有自己的参数对象 | 不创建，使用时查外层 |
| new能力 | 一般function可构造 | 缺少[[Construct]]，不可new |
| prototype | 一般有供实例构造的属性 | 通常没有；手动添加也不赋予构造能力 |
| call/apply/bind | 可指定普通调用this及参数 | 可传/预置参数，不能改变词法this |
| yield | 可写成function*形态 | 不能写成箭头生成器 |
| 简洁返回 | 需要return语句 | 表达式体可隐式返回，返回对象需括号 |

```js
const owner = {
  value: 2,
  run() {
    const arrow = () => this.value;
    return arrow.call({ value: 9 });
  }
};
console.log(owner.run()); // 2
const make = () => ({ value: 1 });
console.log(make().value); // 1
```

对象字面量本身不建立this作用域。把obj.method写成箭头属性，不会自动令this等于obj。需要随接收者变化的对象方法用普通方法；回调需要保留外层this时箭头很合适。

箭头不能new的直接依据是内部构造能力，不是“匿名函数不能new”；匿名的普通函数表达式可以构造。

<a id="k05"></a>

### 5. 形参、实参、arguments、rest 与默认值

形参是声明的接收位置，实参是调用时传入的值。JavaScript按值传参；对象参数持有引用值副本，因此修改对象属性可见，重绑形参不会替换调用方变量。

arguments是普通函数的类数组参数对象；rest是真数组，且只能位于参数列表最后。默认参数在值为undefined或未提供时启用，null不会触发。默认表达式每次调用重新求值，并按参数初始化顺序执行。

```js
function describe(first = 'default', ...rest) {
  return [first, arguments.length, rest.length];
}
console.log(describe(undefined, 2, 3)); // ['default',3,2]
console.log(describe(null)); // [null,1,0]
console.log(describe.length); // 0
```

严格模式和非简单参数列表不会使用旧非严格简单参数中某些arguments与形参联动行为。新代码不要依赖这种历史别名。arguments.callee等旧做法也不适合严格代码；递归优先使用明确函数名。

<a id="k06"></a>

### 6. 返回值与函数属性方法

return结束本次调用并给出值，不写return或return后不带表达式得到undefined。return后换行会受到ASI影响；try/finally也可能改变最终完成结果。

| 属性/方法 | 用途 | 边界 |
| --- | --- | --- |
| name | 函数名称或上下文推断名 | 可被压缩/推断，不当唯一ID |
| length | 第一个默认参数前的形参数量，不计rest | 不是实际实参数量 |
| toString() | 源码式文本或原生函数表示 | 不作为稳定序列化协议 |
| call(thisArg,...args) | 立即调用，逐项实参 | 受目标函数this规则约束 |
| apply(thisArg,argsArray?) | 立即调用，数组/类数组实参 | 不代表接受所有iterable |
| bind(thisArg,...prefix) | 返回绑定函数 | 预置this和参数，不立即调用 |

闭包中的局部状态属于某次调用环境，fn.count这样的自有属性属于函数对象。两者生命周期和共享范围不同，缓存设计不能混淆。

<a id="k07"></a>

### 7. 高阶函数、纯函数、柯里化与偏应用

高阶函数接收函数或返回函数。纯函数要求相同输入得到相同输出且无可观察的外部副作用；读取可变全局、当前时间或修改DOM会破坏这些条件，是否纯不取决于有没有return。

柯里化把多参数函数转成逐次接收参数的函数；偏应用提前固定部分参数。二者通常使用闭包，但概念不同。

```js
const add = (a, b) => a + b;
const curried = a => b => a + b;
const addTen = add.bind(null, 10);
console.log(add(10, 2), curried(10)(2), addTen(2)); // 12 12 12
```

参数默认值和rest会影响fn.length，手写通用curry时应允许明确arity。组合函数还要说明参数个数、this、异步和错误传播约定，不用“函数式”这个名字跳过契约。

<a id="k08"></a>

### 8. 递归、尾调用与重入

递归需要终止条件和趋近终止的步骤。即使逻辑能结束，过深递归也可能耗尽调用栈；深树遍历可用显式栈/队列。不能依赖所有运行时都提供尾调用优化。

重入指前一次调用还没完成就再次进入同一逻辑，例如事件回调内再次emit。它不需要多线程。一次性监听应先移除再执行回调，避免重入触发第二次；状态变更顺序也要按此检查。

## 三、知识小结

函数复述顺序：一等值 → 定义形式 → 执行形态 → this/参数/构造差异 → 返回值与副作用 → 函数应用。不要把“匿名、箭头、回调、async、高阶”排成互斥列表。

## 四、面试题与答案

<a id="c03-01"></a>

### C03-01 [P0·基础] 函数是什么，为什么说它是一等值？

**回答：** 函数是具有调用相关能力的对象，可以像其他值一样赋值、传参、存储和返回。一等值描述这种使用地位，不代表所有函数都可以new或任意改变this。

对应讲解：[函数是什么：可调用对象与一等值](#k01)。

<a id="c03-02"></a>

### C03-02 [P0·基础] 函数有哪些类型？

**回答：** 先分维度。定义形式有声明、表达式、方法简写、箭头和动态构造；执行形态有普通、async、Generator、异步Generator；回调、递归、高阶和构造函数描述使用角色。维度可以重叠，不能互斥罗列。

对应讲解：[定义形式：声明、表达式、方法、箭头](#k02)。

<a id="c03-03"></a>

### C03-03 [P0·原理] 箭头函数与普通函数的主要区别是什么？

**回答：** 箭头不建立自身this和arguments，this沿外层环境读取，call/apply/bind不能改词法this；它没有[[Construct]]能力，不能new。一般普通函数的this主要由调用方式决定，拥有arguments且一般可构造。还要区分方法简写、async和生成器等非一般函数。

对应讲解：[普通函数与箭头函数的区别](#k04)。

<a id="c03-04"></a>

### C03-04 [P0·原理] 函数声明与函数表达式提前调用有何不同？

**回答：** 普通声明通常在所属作用域正文前初始化为函数值；表达式要先求值并赋给变量。var保存表达式时提前读到undefined，调用是TypeError；let/const初始化前访问是TDZ的ReferenceError。不是function关键字本身统一决定结果。

对应讲解：[定义形式：声明、表达式、方法、箭头](#k02)。

<a id="c03-05"></a>

### C03-05 [P0·基础] arguments、rest、fn.length分别是什么？

**回答：** arguments反映普通函数的实际实参，是类数组；rest收集剩余实参得到真数组；fn.length按形参声明计算，到首个默认参数为止且不含rest。实际传入数量用arguments.length，不由fn.length决定。

对应讲解：[形参、实参、arguments、rest 与默认值](#k05)。

<a id="c03-06"></a>

### C03-06 [P1·原理] 回调一定异步吗？匿名函数一定不能new吗？

**回答：** 都不是。回调是由接收方调用的角色，map等回调通常同步；匿名普通函数表达式可以构造，箭头不能构造是因为缺少内部能力，与有没有显式名字无关。

对应讲解：[执行形态：普通、async、Generator](#k03)。

<a id="c03-07"></a>

### C03-07 [P1·基础] 柯里化与偏应用的区别是什么？

**回答：** 柯里化改变接收参数的形态，把多参数调用转为逐次函数调用；偏应用固定一部分参数形成新函数。bind预置参数属于偏应用。实现时要定义arity、this、占位符和超额参数的处理。

对应讲解：[高阶函数、纯函数、柯里化与偏应用](#k07)。

<a id="c03-08"></a>

### C03-08 [P1·工程取舍] 递归为什么会溢出，重入为什么会破坏once？

**回答：** 递归每层通常占用调用栈，深度大时即使有终止条件也可能溢出。重入是回调尚未返回就再次调用相同流程；once若在执行回调后才移除，重入时仍会找到它。应先移除再调用，并测试递归触发路径。

对应讲解：[递归、尾调用与重入](#k08)。

<a id="c03-09"></a>

### C03-09 [P1·编码] 实现参数个数明确的柯里化。

**回答：** 用闭包收集已传参数，达到 arity 时调用原函数；未达到则返回继续收集的函数。此实现面向不依赖动态 this 的函数，不支持占位符；多余实参继续传给目标，arity 显式给出以避免默认参数/rest 影响 fn.length。

```js
function curry(fn, arity) {
  if (typeof fn !== 'function' || !Number.isSafeInteger(arity) || arity < 0) {
    throw new TypeError('invalid function or arity');
  }
  function collect(received) {
    return (...next) => {
      const all = [...received, ...next];
      return all.length >= arity ? fn(...all) : collect(all);
    };
  }
  return collect([]);
}
const add = curry((a, b, c) => a + b + c, 3);
console.log(add(1)(2)(3), add(1, 2)(3)); // 6 6
const withOne = add(1);
console.log(withOne(2, 3), withOne(4, 5)); // 6 10
```

**追问与回答：** 两次从 withOne 继续应独立，不应互相污染参数；因此每次用新数组组合。支持 this 或占位符时必须额外定义绑定和补位规则，不能只增加参数拼接。

对应讲解：[高阶函数、纯函数、柯里化与偏应用](#k07)。
