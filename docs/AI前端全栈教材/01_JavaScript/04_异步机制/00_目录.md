# 异步机制

先分清回调注册与真正执行，再学习 Promise 的结果传递和 await 的暂停恢复，最后用事件循环解释调度、用错误处理连接失败路径。完整轮询和受限手写实现放到基础之后。

## 本组掌握标准

- **基础：** 分清同步调用、回调注册与稍后执行；说明 Promise 状态、then 的结果传递、await 的暂停范围，以及任务和微任务的处理时机。
- **中级：** 按实际完成条件和入队顺序推导输出，改变 resolve、return、throw 或 await 的位置后重新分析；正确组织串行、并发和错误捕获。
- **高级：** 解释等待、取消和让出执行机会的区别；分析任务重叠、未处理拒绝与微任务导致的卡顿，明确运行环境并验证失败和停止路径。
- **自查练习：** 手动控制两个 Promise 的完成次序，预测链式结果；再加入定时器和微任务，验证日志与错误去向。通过完成通知结束检查，不靠随意等待几十毫秒猜测结果。
