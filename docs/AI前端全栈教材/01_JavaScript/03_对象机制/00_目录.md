# 对象机制

先理解对象怎样组织和创建，再追踪构造、属性查找、继承和 class；最后用 Proxy 与 Reflect 观察操作拦截与默认行为转发。先会运行短例，再看完整进阶实现。

## 本组掌握标准

- **基础：** 区分对象、构造函数与实例，说明普通 new 的过程；分清 prototype、对象自身的原型关联和 constructor 属性。
- **中级：** 画出属性查找关系，解释遮蔽、原型替换、继承与 class 成员位置；验证实例状态是否独立、方法是否共享，以及 Proxy 操作是否保留正确的接收者。
- **高级：** 根据需求选择工厂、类、继承或组合，说明接口和共享状态的边界；阅读受限代理或响应式实现时，能指出它支持与缺少的行为。
- **自查练习：** 创建两个实例，验证数组状态各自独立、原型方法共享；再替换构造函数的 prototype，解释旧实例与新实例的查找差异。

整体层次和进入 Vue 的条件见[复习达标标准](../00_学习导航.md#learning-standard)。
