## 二、各知识点详细解释

### 1. 作用域是什么

作用域回答：**一段代码在哪里可以访问某个标识符。**

JavaScript 采用词法作用域，代码写在哪里决定了静态作用域关系。

### 2. var

var 是函数作用域：

```js
function foo() {
  if (true) {
    var x = 1
  }
  console.log(x) // 1
}
```

声明会提升，但初始化位置仍然不同。

### 3. let / const

具有块级作用域：

```js
if (true) {
  let x = 1
}
console.log(x) // ReferenceError
```

### 4. TDZ

let/const 在词法环境建立后，到初始化前存在暂时性死区：

```js
console.log(x) // ReferenceError
let x = 1
```

不能简单理解成“let 没有提升”。更准确地说，绑定已经创建，但在初始化前不能读取。

### 5. 作用域链

当前作用域找不到变量时，会沿外层词法环境继续查找，形成 scope chain。

### 6. 执行上下文

执行上下文描述代码当前执行所需要的运行环境，包括 LexicalEnvironment、VariableEnvironment、PrivateEnvironment 等规范层结构。执行函数调用时会创建新的 Function Execution Context。

### 7. 作用域与执行上下文的区别

作用域是“代码定义在哪里决定能访问什么”；执行上下文是“代码当前运行时需要哪些环境”。两者有关，但不是同一个概念。

## 三、本章面试题与答案

### 题 1：let、const、var 的区别？

**答案：**

var 是函数作用域，let/const 是块级作用域；let/const 存在 TDZ；const 限制的是绑定重新赋值，不代表对象内容不可变。三者都涉及声明实例化和初始化过程，但行为不同。

### 题 2：let 有没有提升？

**答案：**

不要简单回答“没有”。更准确地说，let 的词法绑定会在作用域建立时创建，但在声明执行到初始化之前处于 TDZ，因此访问会抛 ReferenceError。

### 题 3：作用域和执行上下文有什么区别？

**答案：**

作用域描述标识符在代码中的可访问范围，是词法结构；执行上下文描述某段代码正在运行时的执行环境，是运行时概念。函数调用会创建新的执行上下文，而它会按照词法作用域规则建立对外层环境的访问关系。
