# JavaScript 复习清单与代码练习

把每个主题复习到能自述、能推导、能改动一个小例子，就可以继续下一组。遇到细节回正文查，不必一次背完所有 API；完成主线后进入 Vue，扩展应用按项目需要补。

按六个分类查阅[学习导航](00_学习导航.md)，本页按练习任务串联主题。D/C为固定检索编号，与分类内文件顺序独立。

## 先自述概念，再用短例证明

- [值、对象身份与参数](01_数据类型、内建对象与内存管理/01_数据类型、对象身份与参数传递.md)：说明赋值复制了什么、修改对象与重新赋值有什么区别，再推导共享对象的输出。
- [类型判断与校验](01_数据类型、内建对象与内存管理/02_类型判断与运行时校验.md)：说明 typeof、Array.isArray、instanceof 各自证明什么，用反例区分类型标签与业务合法性。
- [var、let、const](02_运行基础/02_var、let、const.md)：区分声明、初始化与赋值，解释提升、TDZ 和 const 限制的是哪种变化。
- [函数与调用](02_运行基础/03_函数.md)：解释函数值、参数、返回与回调角色，为后面的变量查找和调用执行做准备。
- [作用域与作用域链](02_运行基础/04_作用域与作用域链.md)：按定义位置逐层查找变量，区分找到未初始化的绑定与始终找不到变量。
- [执行上下文与调用栈](02_运行基础/05_执行上下文与调用栈.md)：画出嵌套调用的入栈与出栈，说明每次调用的局部变量，以及调用关系与查找关系的区别。
- [this 指向](02_运行基础/06_this指向.md) → [call、apply、bind](02_运行基础/07_call、apply、bind.md) → [闭包](02_运行基础/08_闭包与函数应用.md)：说明当前调用、指定接收者与保存状态。
- [对象创建](03_对象机制/01_面向对象与对象创建.md) → [构造函数与 new](03_对象机制/02_构造函数与new.md)：解释对象组织方式与批量创建，推导普通构造函数的初始化和返回值。
- [原型](03_对象机制/03_原型与原型链.md) → [继承](03_对象机制/04_JavaScript继承方式.md) → [class](03_对象机制/05_class与私有成员.md)：先追踪属性查找，再检查状态独立与方法复用，最后用类语法表达同一组关系。
- [Proxy 与 Reflect](03_对象机制/06_Proxy与Reflect.md)：解释操作经过谁，以及默认行为怎样转发。
- [异步与事件循环](04_异步机制/01_异步基础与定时器.md)：区分注册回调、任务具备执行条件和回调真正运行，再读 [事件循环](04_异步机制/04_事件循环与调度.md)解释顺序。

## 代码推导每次只改一个条件

- [短路与可选链](02_运行基础/01_语法、运算符与严格模式.md#k02)：把 null 换成 0 或空对象，说明哪些表达式还会求值。
- [循环绑定](02_运行基础/02_var、let、const.md#k05)：把 var 换成 let，解释函数读取的是共享变量还是每轮变量。
- [按定义位置查找](02_运行基础/04_作用域与作用域链.md#k02)：改变调用者的同名变量，推导被调用函数会读取哪一层绑定。
- [参数初始化](02_运行基础/05_执行上下文与调用栈.md#parameters)：改变参数次序与实参是否为 undefined，推导默认值求值和 TDZ 错误。
- [this 指向](02_运行基础/06_this指向.md#k01)：依次尝试方法调用、取出后调用和 new，区分普通函数与箭头函数，先识别函数能否构造。
- [call、apply、bind](02_运行基础/07_call、apply、bind.md)：改变接收者、参数传法与调用时机，比较立即执行和返回新函数，并检查绑定函数的构造行为。
- [共享状态与快照](02_运行基础/08_闭包与函数应用.md#k02)：把提前计算的字符串改成调用时计算，解释输出为什么变化。
- [原型查找](03_对象机制/03_原型与原型链.md#k02)：先改实例属性，再改共享数组，说明分别影响哪些对象。
- [继承方式](03_对象机制/04_JavaScript继承方式.md)：记录父构造函数的调用次数，验证实例数组是否独立、方法是否共享。
- [Promise](04_异步机制/02_Promise.md)：在 then 中分别 return 值、return Promise、throw，跟踪下一段的状态与结果。
- [async/await](04_异步机制/03_async与await.md)：把顺序启动改成同时启动，再检查依赖、错误与 finally 的执行时间。
- [事件循环基础与顺序](04_异步机制/04_事件循环与调度.md#process-thread)：先区分页面主线程、调用栈与待执行队列，再加入 Promise、await 和新微任务逐轮推导；区分回调执行阶段与 Node 循环轮数。
- [模块化](05_模块化与浏览器实践/01_模块化.md)：对照 ESM 活绑定与 CommonJS 导出，按文件的初始化顺序解释读取时机。

## 用小实现串起调用与状态

- [常用事件与绑定](05_模块化与浏览器实践/02_DOM操作与DOM事件.md)：比较 onclick 覆盖与多个监听，区分 input/change、表单提交与点击，验证保存同一个函数后能移除。
- [new 教学实现](03_对象机制/02_构造函数与new.md#c10-01)：先说明只支持一般函数构造器，再验证原型关联和显式对象返回值。
- [函数包装](02_运行基础/03_函数.md#k09)：保留 this、参数、返回值与同一异常对象，检查目标只执行一次。
- [一次性回调](02_运行基础/03_函数.md#c03-17)：先说明失败是否消耗机会，再验证重入、取消和重复取消。
- [防抖与节流](05_模块化与浏览器实践/03_防抖与节流.md)：先画时间线，选择首部或尾部契约，验证最后输入、窗口前后和 cancel 后复用。
- [DOM 事件](05_模块化与浏览器实践/02_DOM操作与DOM事件.md)：给动态列表做事件委托，区分 target 与 currentTarget，挂载后触发、卸载后不再触发。
- [Fetch 与请求竞态](05_模块化与浏览器实践/04_Fetch、请求取消与竞态.md)：先处理 HTTP 和解析错误，再模拟旧请求晚返回，保证只有当前请求提交结果。
- [并发池](05_模块化与浏览器实践/05_异步控制与任务调度.md)：传任务函数，记录同时运行数，检查并发上限、结果顺序和失败策略。

每个实现先使用正文约定的有限范围。通过正常例子后，再改取消、同步抛错、异步拒绝或重复调用中的一个条件，不把受限实现当作原生替代。

## 从首组的复制与内存专题串起引用和清理

- [浅拷贝与深拷贝](01_数据类型、内建对象与内存管理/20_浅拷贝与深拷贝.md)：确定需要隔离哪一层，再检查嵌套修改是否影响原对象。
- [堆栈内存](01_数据类型、内建对象与内存管理/21_堆栈内存.md)：区分调用结束与数据仍被使用，解释返回对象和闭包为什么可以继续存在。
- [内存与资源生命周期](01_数据类型、内建对象与内存管理/22_垃圾回收机制、内存泄漏与资源清理.md)：从监听目标、计时器或缓存画出引用关系，明确谁创建、谁清理，以及怎样验证业务结束后不再工作。
- [错误处理](04_异步机制/05_错误处理.md)：区分可以恢复、需要向上传播和主动取消，确保失败路径也执行必要清理。
