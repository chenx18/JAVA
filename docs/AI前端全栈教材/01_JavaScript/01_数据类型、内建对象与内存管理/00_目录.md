# 数据类型、内建对象与内存管理

本组从值与类型进入常用内建 API，再衔接对象复制和内存管理。目录内按三段组织，正文文件统一存放在本分类中。

## 本组掌握标准

- **基础：** 分清原始值与对象，解释赋值、比较和参数传递；根据用途选择常见内建 API，说明返回值及是否修改原数据。
- **中级：** 推导嵌套对象修改与浅深拷贝的结果；检查外部数据的类型、结构和范围，区分调用结束、对象仍被引用与资源需要清理。
- **高级：** 沿引用关系定位长期保留的数据，用堆快照或分配记录验证原因；结合数据规模和生命周期选择复制、缓存与清理方案。
- **自查练习：** 用包含嵌套对象的数组比较赋值、浅拷贝和约定数据范围内的深拷贝，先预测修改结果再运行。进阶再复现一个业务结束后仍被缓存持有的对象，解除引用并观察多次操作后的内存变化，不把“未立即回收”直接判定为泄漏。

整体层次和进入 Vue 的条件见[复习达标标准](../00_学习导航.md#learning-standard)。

本组 22 篇正文、144 道题，文件从 01 连续排到 22；D/C为固定检索编号，与分类内文件顺序独立。

机制篇先给口述总览，再解释概念、原因和运行过程，用短例与条件变化检验理解。API 篇按用途说明功能、调用形式、参数、返回值、是否修改原值和就近注意；两种风格按主题选择。
