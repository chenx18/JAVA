# 运行基础

从语法、声明与函数调用进入变量查找、执行上下文和调用栈，再比较 this、显式调用与闭包。每次只改变一个调用或变量条件，解释结果为何变化。

## 本组掌握标准

- **基础：** 解释声明、初始化和赋值，区分作用域、调用栈与 this；说明参数、返回值和闭包保存的状态。
- **中级：** 根据定义位置查找变量，根据函数类型和调用方式判断 this；能推导循环闭包、方法取出后调用及多次调用产生的独立状态。
- **高级：** 设计可复用的函数接口，保留需要的参数、this、返回值和异常；识别旧状态、重入与清理问题，并写出复现用例。
- **自查练习：** 实现计数器工厂，验证两个计数器互不影响；再把一个对象方法取出、绑定后调用，先预测差异，再运行并解释结果。

整体层次和进入 Vue 的条件见[复习达标标准](../00_学习导航.md#learning-standard)。

本组 8 篇正文、44 道分级题。“知识点归纳与自查”和“试题与答案”分别成节，自查不计入分级题数。文件在本组内从 01 起排序；D/C为固定检索编号，与分类内文件顺序独立。

机制篇先给口述总览，再解释概念、原因和运行过程，用短例与条件变化检验理解。API 篇按用途说明功能、调用形式、参数、返回值、是否修改原值和就近注意；两种风格按主题选择，不要求每篇写成同一种结构。

本组八篇按“知识点导图 → 记忆线 → 正文示例 → 知识点归纳与自查 → 试题与答案”阅读。自查属于知识点归纳：每条问题对应一段口述归纳和一句记忆提示，先遮住归纳回忆，再顺序核对，答错的部分回到正文运行短例。分级题单独用于读码、实现与场景分析，继续沿用原题号。
