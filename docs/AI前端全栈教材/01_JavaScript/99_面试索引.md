# JavaScript 面试索引

题目按知识章节组织，答案和追问位于各篇文末。D代表数据类型，C代表核心知识；题号中的章节号与文件序号对应。

P0为优先掌握，P1为常见进阶，P2为按岗位深入；它们是学习建议，不是必考概率。基础题能准确复述，原理题能推导变化，编码题说明契约并验证边界，工程取舍题讲场景、成本和证据。
