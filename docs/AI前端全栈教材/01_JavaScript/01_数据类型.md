## 二、各知识点详细解释

### 1. JavaScript 类型到底是什么

JavaScript 是动态类型语言：变量本身没有在声明时永久绑定为某种类型，运行过程中可以先绑定数字，再绑定字符串，再绑定对象。真正具有类型的是“值”。ECMAScript 定义八种语言类型：Undefined、Null、Boolean、String、Symbol、Number、BigInt、Object。

工程上常说“基本类型/引用类型”，可以作为方便的分类，但严格讲规范直接定义的是 7 种 primitive 类型和 Object 类型。不要把“引用类型”当成 ECMAScript 的正式类型名。

### 2. 原始值

原始值是不可继续拆成对象属性的语言值。常见的值语义表现为：

```js
let a = 10
let b = a
b = 20
console.log(a) // 10
```

这里 `b = a` 后，b 得到了独立的 Number 值。

### 3. 对象值与引用语义

```js
const a = { count: 1 }
const b = a
b.count = 2
console.log(a.count) // 2
```

更准确的说法不是“b 是 a 的引用传递”，而是变量中保存的对象引用值被复制了，所以 a 和 b 都能访问同一个对象。函数参数依然是按值传递。

### 4. String

String 是原始类型。字符串不可变：

```js
const s = 'abc'
s[0] = 'x'
console.log(s) // 'abc'
```

JavaScript 的字符串基于 UTF-16 code units，因此 `length` 不是“人眼看到的字符数”：

```js
'😀'.length // 2
```

这会影响 emoji、代理项对、光标和文本截取。

### 5. Number

JavaScript 只有一个 Number 类型，而不是独立的 int/float/double。它采用 IEEE 754 双精度浮点数语义，因此会出现：

```js
0.1 + 0.2 === 0.3 // false
```

这是二进制浮点表示有限精度造成的表示误差，不是简单意义上的“计算器算错”。

Number 中还存在：

```text
NaN
Infinity
-Infinity
+0
-0
```

安全整数最大值是 `2^53 - 1`。超过这个范围不能保证每个整数都能被 Number 精确表示。

### 6. Boolean

只有 `true` 和 `false`。条件判断会发生 ToBoolean。常见 falsy 值：

```text
false
0
-0
0n
''
null
undefined
NaN
```

普通对象，包括 `[]` 和 `{}`，都是真值：

```js
Boolean([]) // true
Boolean({}) // true
```

### 7. undefined 与 null

`undefined` 是 Undefined 类型唯一的值，常见于变量已存在但没有实际值、函数没有 return、读取不存在的属性等。

`null` 是 Null 类型唯一值，通常用于显式表达“这里没有对象/当前为空”。

```js
null == undefined  // true
null === undefined // false
```

`typeof null === 'object'` 是历史兼容行为，不代表 null 本身属于 Object。

### 8. Symbol

Symbol 是唯一的原始标识值：

```js
Symbol('id') === Symbol('id') // false
```

可作为对象的 Symbol property key：

```js
const key = Symbol('id')
const user = { [key]: 1 }
```

`Symbol.for('x')` 会通过全局注册表复用相同 key 的 Symbol：

```js
Symbol.for('x') === Symbol.for('x') // true
```

### 9. BigInt

用于任意精度整数：

```js
const n = 123456789012345678901234567890n
```

不能把 Number 和 BigInt 直接混算：

```js
1n + 1 // TypeError
```

因为两边属于不同 Numeric Type。

### 10. Object、Array、Function

Array、Function 等都属于 Object 体系：

```js
typeof [] // 'object'
typeof {} // 'object'
typeof function(){} // 'function'
```

`function` 是 `typeof` 为 callable object 特设的结果，并不意味着函数脱离 Object 类型。

### 11. 类型判断

`typeof`：适合原始类型和 function。

`instanceof`：检查原型链关系。

`Array.isArray`：判断数组。

`Object.prototype.toString.call(value)`：用于更具体的内建对象分类。

例如：

```js
Object.prototype.toString.call(new Date()) // '[object Date]'
```

## 三、本章面试题与答案

### 题 1：JavaScript 有哪些数据类型？

**答案：**

ECMAScript 规范定义 8 种语言类型：Undefined、Null、Boolean、String、Symbol、Number、BigInt 和 Object。通常前七种称为原始类型，Object 是对象类型。数组、函数、Date、Map、Set、Promise 都属于对象体系。

### 题 2：JavaScript 是值传递还是引用传递？

**答案：**

函数参数按值传递。传递对象时复制的是对象引用这个值，因此参数和外部变量可以访问同一对象；修改对象属性会影响外部观察结果，但重新给参数变量赋一个新对象不会改变外部变量的绑定。

### 题 3：为什么 typeof null 是 object？

**答案：**

null 在规范中是独立的 Null 类型。`typeof null` 返回 `object` 属于历史兼容行为，因此不能用 typeof 判断 null 是否为对象。

### 题 4：为什么 [] 是 truthy？

**答案：**

条件判断使用 ToBoolean。普通对象直接是 true，数组是对象，因此空数组仍然是 truthy。它不会先通过 ToPrimitive 变成空字符串。

### 题 5：为什么 0.1 + 0.2 不等于 0.3？

**答案：**

Number 使用双精度二进制浮点语义，部分十进制小数无法被有限精度二进制精确表示，运算时会产生表示误差。因此结果是近似值。

### 题 6：为什么 1n + 1 报错？

**答案：**

现代 ECMAScript 的数值运算会使用 ToNumeric。Number 与 BigInt 会保持各自 Numeric Type；二元数值运算要求两侧最终类型一致，所以 BigInt 与 Number 不能直接混合算术。

### 题 7：typeof、instanceof、Array.isArray 有什么区别？

**答案：**

`typeof` 主要判断原始类型以及 callable function；`instanceof` 判断原型链上是否存在构造函数的 prototype；`Array.isArray` 专门判断数组。跨 realm 场景下 Array.isArray 通常比 `instanceof Array` 更稳。

### 题 8：为什么 function 的 typeof 是 function？

**答案：**

函数属于 Object 类型，但具有可调用内部能力。typeof 的规范语义对 callable objects 返回 `function`，因此这是 `typeof` 对函数的特殊分类，而不是说函数不是对象。
