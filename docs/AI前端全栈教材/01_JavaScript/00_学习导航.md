## 程度

以下层次用于检查主题的掌握深度。先完成主线的基础与代表性练习，再按目标岗位深入高级内容，不要求每篇同时达到最高层次。

**基础：讲清概念，用对常见 API。** 合上资料，能用自己的话解释对象共享、作用域、闭包、this、原型、Promise、事件循环和垃圾回收，并各举一个短例。使用常见 API 时，能说明输入、返回值、是否修改原数据；不熟悉的参数能查文档后正确使用。

**中级：推导变化，独立实现功能。** 面对没背过的短代码，先写出输出与原因，再运行核对；改变调用方式、引用关系或异步完成顺序后，仍能重新推导。能独立实现约定范围的防抖节流、事件订阅、并发控制或请求竞态处理，验证正常、失败和取消等适用路径，并解释实现的限制。

**高级：诊断问题，说明设计取舍并验证效果。** 能复现卡顿、内存持续增长或旧请求覆盖新状态等问题，使用 Performance 记录、堆快照或可控任务找到原因；明确状态、模块和资源归谁管理，比较可行方案，用回归用例或修复前后的测量确认结果。八年以上岗位尤其需要结合真实经历说明自己的职责、决策、效果与限制；阅读篇数和工作年限不能直接证明达到某个职级。

### 怎样自查：留下可核对的结果

- **概念复述：** 选一个主题，不看答案讲清“是什么、为什么、用在哪里”，再用短例证明。
- **代码推导：** 先写预测，再运行；结果不同时找到具体规则或遗漏条件，并重新解释。
- **独立实现：** 写代码前说明输入、返回、错误与适用范围；完成后至少验证正常情况和一种相关边界，异步任务还要检查失败、重复触发及取消是否适用。
- **问题排查：** 保留复现步骤、原因证据和修复验证。练习项目也可以使用，但要明确是实验，不能当成生产经历。

### 什么时候进入 Vue

主线核心概念达到基础要求，并能独立完成一个串联状态、异步与清理的小练习，就可以继续 Vue。例如做一个搜索交互：输入防抖、最新请求结果提交、失败处理和停止时清理。先验证正常、旧请求晚返回、请求失败及停止后不再更新四种情况；卡住的知识点回到对应文章补齐。

高级诊断能力在后续项目中持续训练；完整手写 Promise、深入 Node、Worker、录音等按岗位和项目需要选学，不作为进入 Vue 的统一门槛。练习入口见[复习清单与代码练习](98_复习清单与代码练习.md)。

**后续路线：** JavaScript → [TypeScript](../02_TypeScript/00_目录.md) → Vue 3 → Vue 2 复盘与对比 → HTTP 与浏览器 → 性能与工程化。Java 与 AI 应用按项目需要衔接。

### 两种文章怎样阅读

**机制篇**围绕“是什么 → 为什么 → 怎样运行”展开。先读口述总览，再理解必要术语，顺着短例推导输出，最后改变条件检查易错点；不能只背图上的标签。

**API 篇**围绕用途查阅：基本属性、功能分组、调用形式、参数与返回值、是否修改原值、就近注意。需要判断结果时运行附近短例，不必为查一个方法先通读全部机制。

文章在文首提供 PlantUML 图片预览和可复制源码，字号 14、dpi 100；需要提示边界时使用“注意”，不额外添加导图标题。正文用明确标题和短例解释规则；本页的目录与试题使用查阅表格。

[运行基础](<02_运行基础/00_目录.md>)、[对象机制](<03_对象机制/00_目录.md>)、[异步机制](<04_异步机制/00_目录.md>)、[模块化与浏览器实践](<05_模块化与浏览器实践/00_目录.md>)和[选读扩展](<06_选读扩展/00_目录.md>)共 29 篇提供按知识点对应的导图、记忆线、自查问题和完整口述归纳。先沿导图回忆，再进入“知识点归纳与自查”，遮住口述归纳回答问题，随后核对记忆提示；链接不可用时也可顺序阅读。自查属于知识点归纳，用于检查能否复述；独立的“试题与答案”保留原有分级题，用于读码、实现与场景分析。两部分分开阅读，自查不计入分级题数。选读主题仍按岗位和项目需要选择。
