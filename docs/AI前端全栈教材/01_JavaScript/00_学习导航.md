# JavaScript 系统学习与面试查阅

目标是把知识讲清、补全，并支持查阅、复述和面试练习。按主题学习语言和 API，再用文末题目检验理解；不要求把全部正文逐字背诵。

## 当前阅读入口

本系列分为两套正文：数据类型与内建对象、核心知识。目录链接指向实际章节，知识覆盖清单列出各章负责的范围，题目与答案集中在各章文末。

- [知识覆盖清单](01_知识覆盖清单.md)：每个主题的知识范围、对应练习和深入边界。
- [第一篇：数据类型与类型判断](01_数据类型与内建对象/01_数据类型与类型判断.md)：完整讲解与文末题目。
- [第一套：数据类型与内建对象](01_数据类型与内建对象/00_目录.md)。
- [第二套：核心知识](02_核心知识/00_目录.md)。
- [面试索引](99_面试索引.md)：仅收录已写出的题目。

## 两套内容各自负责什么

| 专题 | 主要任务 | 示例 |
| --- | --- | --- |
| 数据类型与内建对象 | 理解值的行为，查方法参数、返回值和边界 | String、Array、Object、类型转换、集合、日期、正则 |
| 核心知识 | 理解代码为何这样执行，能推导并应用 | 函数、this、闭包、原型、异步、模块、错误、内存 |

学习顺序按依赖走：类型和值 → 常用对象与 API → 作用域和函数 → this/闭包/原型 → Promise/async/事件循环 → 工程应用。复习可以直接定位薄弱主题，不要求熟悉的章节从头再读。

## 章节结构

1. **本章目录**：直接列出具体知识点。
2. **知识讲解**：概念、原因、例子、推导和边界；API 类章节同时提供查阅表。
3. **知识小结**：压缩已经讲清的关系，帮助回忆。
4. **面试题与答案**：放在最后，含对应讲解链接、分级问法、完整回答及必要追问。

只在有助于理解时增加对比表、关系图和代码。知识点本身的组织顺序优先，不机械套相同段落模板。

## 怎么用

查阅时从目录定位 API 或机制；复习时先读正文，自己预测例子输出；面试准备时先独立回答文末题，再查答案和讲解。回答不完整，就记录遗漏的关键词；输出题变一个条件后再推导，判断自己是否真正理解。

P0 为优先掌握，P1 为常见进阶，P2 为按岗位深入；深度用“基础、原理、编码、工程取舍”标注。优先级是学习建议，不是对某年或某家公司考试概率的保证。

前端是本教材的主线，Java 与 AI 是横向能力。基础章节以通用前端场景解释，AI 请求、流式界面等放在对应应用章节。

## 范围与使用边界

语言机制示例与浏览器、Node 专用示例分别注明运行条件。手写实现注明支持范围，不将教学模型当作完整原生实现。API 的新旧支持按目标运行时核对；完整前端面试还需要框架、浏览器网络、工程化和真实项目，这些由其他系列负责。

2026 年的复习重点仍应结合实际岗位：语言基础、框架应用与机制、工程质量和项目交付。AI 工具使用及 AI 应用能力作为横向补充；2027 年的岗位变化属于观察和预测，不据此伪造必考清单。公开题库用于核对常见问法，MDN、规范和运行示例用于校准机制。
