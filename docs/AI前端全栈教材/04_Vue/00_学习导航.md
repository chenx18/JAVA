## 程度

**基础：** 能独立写出组件、响应式状态、表单、路由和 Store，并解释常见 API 的效果。

**中级：** 能处理组件协作、异步竞态与资源清理，用测试验证行为，解释更新和复用机制。

**高级：** 能围绕真实问题追踪关键源码、定位成本，并用证据说明设计取舍。原理、工程诊断与架构决策逐层衔接。

基础篇保留必要原理和工程追问；源码篇集中解释内部结构、调用路径与教学实现。各分目录提供更具体的掌握标准。后续主线为 Vue 2 复盘 → HTTP 与浏览器 → 性能与工程化 → 架构与系统设计。
