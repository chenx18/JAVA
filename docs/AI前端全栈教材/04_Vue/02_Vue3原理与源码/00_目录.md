# Vue 3 原理与源码

共 17 篇正文、81 道题。按“应用入口 → 首次运行 → 响应式 → 更新与卸载 → 编译及特殊路径”阅读，用同一个父子计数器贯穿源码。

[程度](#level) · [目录](#catalog) · [试题](#interview)

<a id="level"></a>

## 程度

**基础：** 能运行共同案例，区分应用对象、组件定义、组件 VNode、运行实例、subTree 与 DOM，解释 createApp 和 mount 分别何时工作。

**中级：** 能从一次读取追到依赖，再从一次修改追到调度、render 和 patch；能说明生命周期钩子的登记与调用、父子组件更新及卸载时的停止责任。

**高级：** 能在固定版本源码中定位关键入口，改变调用时机、依赖关系或组件身份后重新推导，用验证结果说明边界和项目取舍。掌握源码主线不等于需要背完整仓库。

**版本与范围：** Vue 3.5.43，先看浏览器普通同步客户端组件。Vue 2 的 new Vue 入口、旧 Watcher 与 nextTick 实现不直接套用到这里；异步 setup、SSR 水合和 KeepAlive 在后续按分支阅读。

### 阅读路线：先走通一遍，再深入模块

- **第一次启动：** 01–04。观察 createApp 后没有 setup、mount 如何创建实例和 DOM、同步父子 mounted 怎样完成。
- **同一次修改：** 05–12。追主例 count、doubled 与 watch 的订阅，观察三次同步修改如何进入一次刷新，再扩展列表 Diff。
- **组件结束：** 11、13。观察修改后立即卸载，区分已排队任务、响应式作用域、缓存停用和外部资源。
- **理解编译位置：** 14–15。SFC 通常在浏览器运行入口前已经编译；目录放在这里是为了在了解运行时后解释优化，并非实际执行到这里才编译。
- **按需进入分支：** 16–17。Teleport、Suspense 和迷你实现用于扩展与验证，SSR 基础见第 04 篇后半部分。

代码与源码入口见[第 01 篇](01_源码地图与运行主线.md)。后面的[迷你实现](17_手写迷你Vue.md)附[教学运行时](examples/mini-vue.mjs)和[教学交互页](examples/index.html)，它与真实 Vue 的共同案例是两组不同用途的实验。

新增图只提供可展开的“PlantUML 源码”，字号 14、dpi 100。源码链接固定 tag，内部字段仅用于说明和调试；模拟 DOM、源码观察与真实浏览器性能验证是不同证据。
