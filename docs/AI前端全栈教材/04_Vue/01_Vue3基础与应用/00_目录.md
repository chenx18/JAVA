## 程度

**基础：** 能独立创建 Vue 项目，写出模板与表单，正确使用响应式 API、组件输入事件、生命周期、路由和 Store。能够说明代码放在哪里、参数是什么、修改后界面为何更新。

**中级：** 能组织组件和组合式函数，处理加载、失败、请求竞态与清理；区分共享状态、页面状态和 URL 状态。能推导组件复用、watch 和 nextTick 的行为，并用组件测试验证正常与异常路径。

**高级：** 能从具体问题追到依赖、调度、渲染或编译环节，测量主要成本，解释方案取舍和限制。八年以上岗位应结合真实项目说明职责、证据与演进，原理追问和工程诊断不都等于架构设计。

**阅读安排：** 先修 [JavaScript](../../01_JavaScript/00_学习导航.md) 与 [TypeScript](../../02_TypeScript/00_目录.md)。先完成基础用法和应用，再读原理；需要源码级解释时，从 [源码地图与运行主线](../02_Vue3原理与源码/01_源码地图与运行主线.md)开始，按 [源码目录](../02_Vue3原理与源码/00_目录.md)追踪同一个应用。后续为 Vue 2 复盘与对比 → HTTP 与浏览器 → 性能与工程化 → 前端架构与系统设计。

**使用方式：** 机制篇按口述结论、短例、运行过程与工程追问展开；API 篇先说明用途、参数、返回或效果，再看注意点。原有知识导图保留，新增过程图只提供可展开的“PlantUML 源码”，字号 14、dpi 100；按正文位置阅读执行顺序和状态变化。

**示例范围：** 基线为 Vue 3.5.43、TypeScript 5.9.3、Vue Router 4.6.4、Pinia 3.0.4；新 API 在正文标注版本。单组件例子放入已有 Vue + TypeScript 项目，多文件例子按所标文件名组合；入口和依赖按正文说明配置。类型检查、组件测试与真实浏览器验证分别提供不同证据。

**阶段练习：** 先运行 [业务表单完整例](25_业务表单、请求状态与页面协作.md)，再完成 [搜索页面与验证清单](24_性能排查、测试与项目练习.md)：查询、列表、路由详情、旧请求晚返回、失败和卸载清理都能解释并验证，就可以进入后续专题。
