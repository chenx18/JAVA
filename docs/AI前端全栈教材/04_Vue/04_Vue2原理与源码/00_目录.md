## 程度

**基础：** 已能使用 [Vue 2 基础与应用](../03_Vue2基础与应用/00_目录.md) 中的常用 API，能够描述一次状态修改后的可观察行为。

**中级：** 能解释 Observer、Dep、Watcher 的关系，跟踪 computed、watch、更新队列、render 与 patch 的执行过程，区分同步修改与异步提交。

**高级：** 能在固定版本源码中定位关键入口，用可复现的短例验证分支依赖、列表复用和资源清理，并说明旧项目维护或迁移的取舍。

**版本与边界：** Vue 2 源码固定为 2.7.16，比较时使用 Vue 3.5.43。源码链接锁定 tag；教学流程图会省略次要分支，不应当作每个版本都完全相同的调用清单。Vue 2 的双端 Diff 与 Vue 3 的列表优化需要分别理解。

**阅读方式：** 先观察实际行为，再顺着正文给出的函数入口追源码，最后改一个条件检查结果。模拟 DOM 测试不替代真实布局、动画与生产环境性能测量。
