## 程度

**基础：** 能读懂并维护 Vue 2 的 Options API 组件，正确使用模板、表单、组件通信、生命周期、Router 3 和 Vuex 3。

**中级：** 能识别新增属性、数组修改、异步更新及组件复用的边界，处理监听、定时器和旧请求的清理，避免把 Vue 3 写法直接套入旧项目。

**深入：** 遇到响应式和更新过程追问时，进入 [Vue 2 原理与源码](../04_Vue2原理与源码/00_目录.md)，沿具体问题阅读，不要求基础阶段背完整源码。

**示例范围：** 基线 Vue 2.7.16、Options API、普通 JavaScript；路由使用 Vue Router 3.6.5，状态管理使用 Vuex 3.6.2。已有项目优先核对锁定版本。常见 Options API 用法也适用于 Vue 2.6，涉及版本变化时以正文说明为准。Vue 2.7 的 Composition API 不代表底层换成了 Proxy。

**阅读方式：** 先看短例，尝试修改一个条件，再用文末试题复述。SFC 例子放在已有 Vue 2 构建项目；HTML 入口注明完整构建。源码与浏览器布局、网络、权限的验证是不同环节。
