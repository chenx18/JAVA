## 程度

**基础：** 能给变量、对象、数组和函数写出合适类型，独立运行类型检查，解释一个错误为什么发生。先掌握正确用法，再分析类型推断和边界。

**中级：** 能根据业务数据设计接口、联合和泛型，正确收窄未知值，说明断言、只读和工具类型在运行时不提供哪些保证，并验证合法与非法输入。

**高级：** 能定位类型与模块配置问题，设计公共组件或库的契约，解释复杂类型的取舍，结合运行校验、类型检查和真实行为验证方案。高级类型的复杂程度不作为能力目标。

**阅读安排：** 先修[JavaScript](../01_JavaScript/00_学习导航.md)，后续按 TypeScript → Vue 3 → Vue 2 复盘与对比 → HTTP 与浏览器 → 性能与工程化推进。Vue 与 TypeScript 衔接篇可以在学完 Vue 3 后回看。

**怎样使用：** 机制篇先讲概念和必要性，再用最小示例解释运行或检查过程，最后进入边界与试题。工具类型等用法篇按功能说明输入类型、得到的类型、短例和注意点。PlantUML 图提供图片与可复制源码，字号 14、dpi 100；图中的术语都应能在正文找到解释。

自查时先预测编译是否通过，再说明原因并运行检查；需要运行的例子再核对输出。目录顺序和题号已同步，旧链接会转到新位置。

**验证范围：** 本系列采用 TypeScript 5.9.3，开启 strict、exactOptionalPropertyTypes、noUncheckedIndexedAccess。独立 TS 示例先在固定严格选项下检查；@ts-expect-error 用来证明错误分支确实被发现。类型专用示例不需要运行，模块组需要配套文件，Vue 示例需要 SFC 编译与 vue-tsc 检查。通过类型检查不等于已经验证真实接口、权限或浏览器交互。
