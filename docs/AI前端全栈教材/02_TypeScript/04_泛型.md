## 二、各知识点详细解释

泛型解决的是：**保留不同类型之间的关系，而不是把类型信息抹掉。**

```ts
function identity<T>(value: T): T {
  return value
}
```

调用：

```ts
const n = identity(1) // number
const s = identity('x') // string
```

### 泛型约束

```ts
function getLength<T extends { length: number }>(value: T) {
  return value.length
}
```

这里不是说 T 只能是某一个具体类型，而是 T 必须满足约束。

## 三、本章面试题与答案

### 题：泛型解决什么问题？为什么不用 any？

**答案：**

any 会放弃大量类型检查，而泛型可以保留输入和输出之间的类型关系。例如 `identity<T>(x: T): T` 能让调用方继续获得具体类型。泛型的价值是“类型关系被保留下来”。
