# 第二章 原始类型、联合类型与交叉类型

## 一、本章具体知识点

- string / number / boolean
- null / undefined
- object
- array / tuple
- union
- intersection
- literal type
- readonly
- optional property
- index signature

## 二、各知识点详细解释

### 联合类型

```ts
type Status = 'idle' | 'loading' | 'success' | 'error'
```

表示一个值属于多个候选类型中的一个。

### 交叉类型

```ts
type A = { id: string }
type B = { name: string }
type User = A & B
```

表示同时满足 A 和 B。

### Tuple

```ts
type Point = [number, number]
```

Tuple 比普通数组更精确地描述位置和长度。

### 可选属性

```ts
interface User {
  name: string
  age?: number
}
```

读取时要考虑 undefined。

## 三、本章面试题与答案

### 题：union 和 intersection 的区别？

**答案：**

union `A | B` 表示值只需要满足 A 或 B；intersection `A & B` 表示同时满足 A 和 B。联合类型常用于状态建模，交叉类型常用于组合多个结构。
