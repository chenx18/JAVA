# 第十一章 组件通信

## 一、本章具体知识点

- props
- emits
- v-model
- defineModel
- slots
- scoped slots
- attrs
- provide/inject
- expose
- defineExpose

## 二、各知识点详细解释

组件通信要先区分数据关系：

```text
父 → 子       props
子 → 父       emit
双向模型      v-model
跨层级        provide/inject
插槽内容      slots
命令式暴露    expose
```

不要把所有东西都塞进 Pinia。局部通信应优先使用组件自身机制。

## 三、本章面试题与答案

### 题：provide/inject 适合什么？

**答案：**

它适合跨多层组件共享某类上下文，例如主题、服务、表单上下文。它减少了逐层 props 传递，但不要把所有全局状态都放进去；需要跨模块共享和调试时可以考虑 Pinia 等更明确的状态系统。
