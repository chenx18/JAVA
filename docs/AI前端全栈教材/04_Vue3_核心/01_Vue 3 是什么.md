## 二、各知识点详细解释

Vue 的核心是：**描述 UI 状态与结构，并让状态变化自动反映到 UI。**

典型组件：

```vue
<script setup lang="ts">
import { ref } from 'vue'

const count = ref(0)
</script>

<template>
  <button @click="count++">
    {{ count }}
  </button>
</template>
```

这里发生了：

```text
count
→ reactive state
→ render effect 读取 count
→ track dependency
→ count 改变
→ trigger
→ scheduler
→ component update
```

Vue 3 的 Composition API 是一组通过函数组合组件逻辑的 API；其核心 Reactivity API 包括 `ref`、`reactive`、`computed`、watchers 等。([vuejs.org](https://vuejs.org/guide/extras/composition-api-faq))

## 三、本章面试题与答案

### 题：Vue 的核心思想是什么？

**答案：**

Vue 是声明式组件框架。开发者描述状态和 UI 之间的关系，Vue 通过响应式系统追踪状态依赖，并在状态变化时调度组件更新。Vue 3 同时结合 Composition API、编译器和虚拟节点等机制提高复用性和运行时效率。
