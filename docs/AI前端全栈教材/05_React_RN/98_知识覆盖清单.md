## 使用与深入

- 查知识时先看概念、例子和边界；复述时按定义、机制、具体例子与条件展开。
- 编码题先明确契约，再检验空值、失败、取消、重入或并发等适用边界；实现的限制写在对应章节。
- 系统设计与项目案例是教学场景，不能直接当作个人生产经历或已验证规模。
- 框架、协议和平台特性按目标版本核对，类型检查、编译、模拟环境和真实集成是不同证据。
- 新API和未来趋势不替代基础；前端为主力，Java与AI围绕已实践的交付能力展开。
