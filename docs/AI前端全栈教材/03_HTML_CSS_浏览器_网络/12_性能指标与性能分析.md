## 二、各知识点详细解释

现代 Web 性能不能只说“首屏快”。需要拆成网络、渲染、交互和稳定性多个阶段。

```text
TTFB → FCP → LCP
              ↓
             INP
              ↓
             CLS
```

DevTools 中要看：

- 网络瀑布
- Long Task
- Layout/Paint
- JS 执行
- 内存快照

性能优化必须基于测量结果，而不是单纯背优化口诀。

## 三、本章面试题与答案

### 题：一个 Vue 页面加载很慢怎么排查？

**答案：**

先区分网络慢还是执行慢：看 Network 的 TTFB、资源大小和瀑布；再看 Performance 的长任务、JS parse/evaluate、layout/paint；再检查首屏 bundle、第三方脚本、图片、接口数量和缓存。定位原因后再决定拆包、懒加载、SSR、缓存或组件优化。
