## 二、各知识点详细解释

Cookie 主要是 HTTP 状态和会话机制的一部分，可以自动随符合条件的请求发送；HttpOnly Cookie 无法由前端脚本读取，常用于降低某类 XSS 导致的 token 直接被脚本读取风险。

LocalStorage 和 SessionStorage 属于 Web Storage，适合简单键值数据，不适合大规模数据库场景。

IndexedDB 适合更结构化、容量更大的浏览器持久化数据。

Cache Storage 常用于 Service Worker / PWA 缓存响应。

## 三、本章面试题与答案

### 题：JWT 放 LocalStorage 和 Cookie 各有什么风险？

**答案：**

LocalStorage 中的 token 可以被当前 origin 的 JS 读取，因此一旦发生 XSS，token 暴露风险较高。HttpOnly Cookie 可以避免 JS 直接读取，但要同时考虑 CSRF，因此通常需要 SameSite、CSRF token 等配合。最终选择应结合威胁模型。
