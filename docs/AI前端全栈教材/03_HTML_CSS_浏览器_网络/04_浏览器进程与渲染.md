## 二、各知识点详细解释

浏览器通常采用多进程架构，具体进程划分属于浏览器实现。渲染器负责页面的 HTML/CSS/JS 等执行与渲染，网络等工作可能由独立进程或线程负责。

页面渲染可抽象为：

```text
HTML
→ DOM

CSS
→ CSSOM

DOM + Style
→ Render Tree
→ Layout
→ Paint
→ Composite
```

### Layout

决定元素几何位置与尺寸。

### Paint

把绘制命令生成图形内容。

### Composite

把不同图层合成最终画面，某些动画如果只改变合成属性，可以减少主线程布局和绘制工作。

## 三、本章面试题与答案

### 题 1：什么是重排和重绘？

**答案：**

重排是几何布局发生变化，需要重新计算受影响元素的位置和尺寸；重绘是视觉样式变化但不一定影响几何结构。重排通常可能进一步触发重绘，因此频繁读写布局属性会产生性能问题。

### 题 2：为什么 transform 动画通常比改变 left 更适合性能？

**答案：**

很多 transform 动画可以在合成阶段完成，减少主线程上的 layout/paint 工作；而修改 left 等布局属性可能触发布局计算。最终是否更快仍要通过 Performance 面板验证。
